# 世界编辑器需求文档

- 状态：需求草案，尚未实施。
- 日期：2026-11-25。
- 适用产品：Another Earth 地图工作台。
- 目标：在现有侧边栏中增加统一编辑入口，支持地形、矢量要素和地图风格编辑。
- 范围说明：本需求是对现有生成与观察工作台的扩展，不表示编辑器已交付，也不同时启动动态文明或历史分支开发。

## 1. 需求来源与约定

### 1.1 用户已明确的需求

1. 侧边栏增加一个“编辑”按钮开关。
2. 开启后显示二级编辑菜单。
3. 二级菜单包含“地形编辑器”“要素编辑器”“风格编辑器”，并允许后续扩展。
4. 地形编辑器通过笔刷抬高或降低地形高度。
5. 要素编辑器用于编辑国界、交通线、城镇位置点等矢量要素。
6. 风格编辑器基于项目当前 Style Spec 自定义地图样式。
7. 地形与要素编辑以 2D 为主要工作视图，默认使用等距圆柱投影（Equirectangular）；3D 用于预览和辅助检查，风格编辑保留当前视图。
8. 激活编辑器或要素类别时自动配置适合任务的工作图层；地形编辑默认显示高程专题图。
9. 工作视图允许用户调整，退出编辑后恢复浏览配置；临时编辑显示不写入自定义样式。
10. 本轮讨论的草稿、应用、保存、精度提示、笔刷反馈、关联冲突、输入隔离和稳定高程色阶要求一并纳入本需求。

### 1.2 文档状态与待细化内容

本文记录已明确的需求和本轮要求同步的交互规则，作为后续设计与验收依据。参数数值、快捷键映射、技术实现和分批顺序仍是建议或待细化项，不视为已经逐项确定。

本文描述目标行为。当前项目仍以源码和现有契约为准，不能把本需求中的能力写成既有实现。

## 2. 产品目标

用户无需离开地图工作台，即可选择编辑工具，直接调整世界或地图表现，并看到操作结果。编辑后的地图、对象资料和统计应保持一致，操作能够撤销，成果能够保存和恢复。

三类编辑对象的区别如下：

| 编辑对象 | 修改内容 | 生效结果 |
| --- | --- | --- |
| 地形 | 世界高程及其必要关联事实 | 地表与受影响自然系统更新 |
| 要素 | 土地归属、交通路径、聚落位置与属性 | 几何、资料和统计同步更新 |
| 风格 | 地图样式文档 | 颜色、线型、符号、文字等显示更新 |

## 3. 范围与优先级

### 3.1 首版目标

三类编辑器均属于本需求的首版目标，可以分批实现；仅完成菜单或改名功能不代表本需求已交付。

| 编号 | 范围 | 首版必须具备 |
| --- | --- | --- |
| ED-NAV | 编辑入口 | 开关、二级菜单、当前编辑器与工具状态、默认视图与工作图层、退出恢复 |
| ED-TER | 地形编辑 | 抬高、降低、笔刷范围和参数、预览、关联更新 |
| ED-FEA | 要素编辑 | 国家领土调整、已有交通线改线、已有城镇移动，以及受支持属性编辑 |
| ED-STY | 风格编辑 | 基于现有规范的可视化属性编辑、JSON 编辑、校验和实时预览 |
| ED-HIS | 操作恢复 | 完整操作粒度的撤销、重做、失败恢复 |
| ED-SAVE | 成果保存 | 编辑后世界与自定义样式的导出、导入和一致恢复 |

### 3.2 后续扩展

- 地形平滑、平整、山脊、峡谷、噪声等工具。
- 国家创建、删除、拆分、合并，以及外交、行政区等编辑。
- 交通线创建与删除、城镇创建与删除、人口结构编辑。
- 河流改道、湖泊、资源、生态、文化和宗教编辑。
- 自定义注释、纹章与地图装饰。
- 多选、框选、批量编辑、复制和对象锁定。
- 3D 地形笔刷，以及等面积、墨卡托等其他投影下的直接修改工具。
- 浏览器项目列表、自动保存、跨会话完整操作历史。
- 动态模拟、历史时点编辑和历史分支。

扩展项不作为首版的隐含前置条件。导航结构应容纳新增编辑器，但首版不显示无法使用的空工具入口。

## 4. 编辑入口与工作区

### 4.1 侧边栏开关

- 现有侧边栏新增“编辑”图标按钮，具有中文、英文名称及悬停提示。
- 默认关闭，开启时按钮持续显示激活状态，并显示二级编辑菜单。
- 二级菜单固定提供“地形编辑器”“要素编辑器”“风格编辑器”。
- 初次开启只展示菜单，不自动启用会修改地图的工具；再次开启可恢复上次选择的编辑器，但需要用户明确激活修改工具。
- 同一时间只激活一个编辑器中的一个地图修改工具。
- 关闭编辑模式时隐藏二级菜单、工具面板、笔刷及编辑控制点。已应用的修改保留。
- 有未应用草稿时，关闭编辑模式须提供“应用并退出”“放弃草稿”“继续编辑”；应用失败则保留草稿和编辑模式。
- 未保存但已应用的修改以持续状态提示，关闭编辑模式本身不等于丢弃或保存。

### 4.2 二级菜单与工具面板

- 二级菜单位于主侧边栏邻侧，负责选择编辑器；具体工具、参数和选中对象属性在对应面板显示。
- 当前编辑器、工具、选中对象、未应用状态和计算中状态应清晰可见。
- 地图工作区保持可操作，菜单和面板不覆盖全部地图。
- 与现有参数、图层、概览和探测面板协调互斥，避免多个主要面板重叠；切换面板不得静默丢弃草稿。
- 编辑器提供必要的对象信息，用户无需依赖同时打开独立探测面板才能选中或编辑对象。
- 无有效世界时禁用地形与要素修改并说明原因；风格编辑可修改文档，地图预览需要有效世界。
- 没有文明数据时，国家、交通和城镇工具显示不可用原因，地形与风格编辑仍可使用。

### 4.3 默认视图与投影

| 编辑器 | 激活时的默认视图 | 首版修改能力 |
| --- | --- | --- |
| 地形编辑器 | 2D 等距圆柱投影 | 在此视图中提供完整地形笔刷操作 |
| 要素编辑器 | 2D 等距圆柱投影 | 在此视图中提供领土、交通线和城镇修改 |
| 风格编辑器 | 保留当前视图和投影 | 可在现有 2D/3D 视图中编辑并预览受支持样式 |

- 点击主侧边栏“编辑”只展开二级菜单，不立即切换视图或投影。
- 首次激活地形或要素编辑器时切换到等距圆柱投影，并尽量保留当前关注区域和相近的地理尺度，避免无故跳回全图。
- 首版地形和要素的直接修改集中在等距圆柱投影；等面积投影、墨卡托与 3D 用于查看结果，切入这些预览视图时暂停地图修改工具并说明当前为预览。
- 提供便捷的 3D 预览和返回编辑入口；返回时恢复编辑视图的取景、工具参数、草稿与选中对象。
- 后续增加其他投影的直接修改能力后，可记住用户上次选择的受支持编辑投影；首版不记忆为无法修改的工作投影。
- 等面积投影用于检查领土面积分布和整体构图；墨卡托可查看中低纬度局部，不能作为覆盖极点的全球编辑视图。
- 所有视图读取同一份编辑结果；切换视图或投影不改变世界事实，不清空已完成草稿。
- 退出编辑时恢复进入前的视图模式、2D 投影和浏览图层配置，尽量保留最后关注位置；正在进行的操作和草稿按退出规则处理。

### 4.4 编辑工作图层

激活编辑器或要素类别时自动配置临时工作图层，使用户可以直接开始操作。

| 编辑模式 | 自动显示 | 辅助信息 |
| --- | --- | --- |
| 地形编辑 | 高程专题图 | 海岸线、海平面分界、适度晕渲、笔刷范围和当前位置高程 |
| 国家与边界编辑 | 国家领土填色、国界 | 国家名称、目标国家高亮、待划入或划出区域 |
| 交通线编辑 | 交通线、城镇节点 | 淡化地形底图、河流与海岸、路线途经点和控制点 |
| 城镇编辑 | 城镇位置点与名称 | 地形底图、海陆与湖泊、关联交通线 |
| 风格编辑 | 当前正在编辑的样式 | 可选图层高亮或单独预览，由用户控制 |

- 自动配置只在激活编辑器或切换要素类别时执行，不在每次选择工具、落笔或更新草稿时强制重置。
- 地形编辑默认淡化或隐藏遮挡高程的国家填色和密集文字；用户仍可打开城镇、国界等参考图层并调整透明度。
- 网格和等高线属于可选辅助显示，等高线可作为后续增强；不因提出辅助显示而隐含新增完整数据源的首版要求。
- 工作图层使用现有数据能力；缺少文明等数据时显示不可用原因。
- 临时可见性、淡化与选中高亮属于编辑工作区状态，不改写样式文档，也不自动成为该样式的默认启用配置。
- 进入风格编辑器时移除地形或要素编辑附加的临时专题、淡化和高亮，基于当前已应用样式及其草稿显示真实效果。
- 风格编辑中可临时启用或单独预览某层；把可见性写入样式默认值仍需明确操作。
- 退出时撤销编辑工作区的临时覆盖。已应用的自定义样式保持生效，不因恢复浏览配置而回滚；图层 ID 已变化时只恢复仍有效的配置。
- 编辑期间调整的工作图层可在当前会话内记住，但不替换进入编辑前的浏览配置。

### 4.5 地图交互与输入隔离

- 建议用左键执行当前工具，按住空格临时使用现有地图拖动操作；滚轮保留缩放，光标明确区分修改与导航。
- 修改工具和地图平移互斥，临时导航不得产生笔画或移动对象。
- 指针在面板、输入框或菜单上操作时，不向地图穿透；文本输入时空格等按键优先作为文字输入。
- 地形或要素编辑期间暂停自动旋转，离开编辑模式后可恢复进入前状态。
- `Esc` 优先取消正在进行的拖动或操作，再解除当前地图修改工具；不以一次按键静默丢弃整个草稿。
- 视图、投影或编辑器切换前先结束或取消当前拖动，不允许一笔跨越两个工作视图；已完成草稿按相应切换规则处理。
- 指针离开可编辑地图区域时暂停作用，重新进入后不沿离开期间的路径自动补画；松开指针、丢失捕获或窗口失焦时结束本笔，不能继续累积修改。明确取消则恢复本笔开始前状态。
- 切换投影、进入 3D 预览再返回时，选中对象按稳定身份恢复。

### 4.6 球面尺度与编辑精度

- 笔刷半径按球面实际距离计算，作用范围再投影到屏幕；高纬度可以显示拉宽或变形的范围，不把固定屏幕圆当作实际圆形笔刷。
- 面积和距离从世界球面数据计算，不能使用投影后的屏幕面积或线长作为权威值。
- 等距圆柱的左右边界连续：笔刷、领土和线路跨越 ±180° 经线时，正确更新并显示两侧，不穿过整幅地图形成错误连线。
- 高纬度、极点与投影边缘的修改按球面位置处理，并提供 3D 检查入口。
- 根据当前网格可表达精度提供按需网格显示、区域高亮或吸附落点提示，帮助用户理解最终修改范围。
- 笔刷小于网格尺度，或城镇拖动后仍位于原区域时，明确提示实际未改变的原因，不营造亚网格精确编辑的错觉。

## 5. 地形编辑器（ED-TER）

### 5.1 首版工具和参数

| 项目 | 要求 |
| --- | --- |
| 抬高 | 增加笔刷范围内的地形高程 |
| 降低 | 减少笔刷范围内的地形高程 |
| 半径 | 以公里显示实际作用半径，不随缩放改变 |
| 强度 | 控制单位作用时间内的高程变化速率，优先使用米/秒等直观单位 |
| 边缘衰减 | 控制从中心到边缘的作用过渡，至少提供柔和笔刷 |
| 光标 | 显示球面作用范围、当前工具及中心高程；操作时显示草稿高程与本次变化量 |

参数范围、步长和默认值需要结合现有高程单位、网格分辨率及真实交互调校，不在需求阶段凭空规定数值。

### 5.2 笔刷行为

- 按下并拖动形成一笔，抬起后结束该笔；取消拖动恢复本笔开始前的状态。
- 作用范围由球面距离确定，不随窗口大小或投影改变实际半径。
- 相同轨迹、持续时间和参数下，结果不应明显依赖帧率或指针事件数量。
- 拖动期间提供连续高程预览；一笔包含的所有格子属于一个草稿撤销单元。
- 连续多笔可累积为草稿，用户可撤销、重做或放弃草稿，再统一应用。
- 笔刷小于网格可表达尺度时给出反馈，不能表现为工具无故失效。
- 首版保持当前网格和分辨率；提高网格等级不属于地形笔刷功能。

### 5.3 高程图与变化反馈

- 地形编辑默认显示陆地高程和海底深度，图例明确单位、海平面零值和当前色阶范围。
- 使用稳定的绝对高程色阶。一次笔画或出现新的最高/最低点时，不自动重新归一化整张地图的颜色。
- 用户可主动调整显示范围或重置到默认色阶；超出当前范围的数值提供可辨识反馈，实际高程不因颜色显示上限被截断。
- 笔刷位置显示当前有效高程、草稿高程和变化量，以明确数值帮助判断修改。
- 海岸预览随草稿高程更新，抬升成岛或陆地下沉可直接看见；其余尚未重算的自然或文明内容标为未同步或暂时隐藏。
- 可选“本次变化量”显示以本次草稿开始时的世界为参照，分别标识抬高、降低和无变化区域，便于定位本次修改；该显示是辅助预览，不改写保存样式。
- 保留适度晕渲帮助识别山脊和坡面；修改预览所需的晕渲应随草稿更新，不能使用旧效果误导地形判断。

### 5.4 应用与关联影响

- 编辑器区分“高程预览”和“已完成关联更新的有效世界”。预览中不得把旧河网、旧统计等展示为已同步的新事实。
- 应用前说明受影响系统；海岸变化或存在城镇、交通、领土冲突时，列出相关对象和需要处理的事项。
- 改变高程后，更新海陆一致性及必要的地理、气候、冰雪、水文、生态、资源和派生查询，最终通过完整世界校验。
- 允许首版按受影响的整个生成阶段重算，不要求首次交付即支持局部流域算法。
- 重算必须使用编辑后的地形，并纳入输入身份；不能按原始参数重新生成后覆盖笔刷结果。
- 人口、城镇、文化、宗教和国家不得在应用地形时被无提示地重新抽取或删除。
- 对新地形下仍有效的文明事实优先保留；对沉入海中的城镇、无效交通路径或领土等冲突，提供定位和处理说明。首版可阻止提交并要求用户调整草稿；不要求自动迁城或自动重建文明。
- 计算期间显示进度并支持取消。失败或取消后保留原有效世界，并允许用户继续处理草稿。
- 成功应用后，地图、探测信息、图例和统计均基于同一有效世界。

## 6. 要素编辑器（ED-FEA）

### 6.1 选择与属性

- 按“国家与边界”“交通线”“城镇”选择编辑类别，地图拾取优先命中当前类别。
- 选中对象后高亮，并显示名称、类别、位置或归属以及可编辑属性。
- 多个对象重叠时提供候选选择，避免因绘制顺序而无法选到目标。
- 隐藏图层中的对象不应无提示地被选中；启用工具时可提示打开对应图层。
- 保留已有对象的稳定 ID，改名或移动不会创建一个新的身份。
- 每项操作明确影响范围。未支持的属性显示只读状态，不提供无效输入。

#### 世界事实与外观的操作边界

| 用户意图 | 编辑入口 | 实际影响 |
| --- | --- | --- |
| 移动城镇位置 | 要素编辑 | 聚落位置及必要人口、交通关联 |
| 调整城镇符号大小或文字偏移 | 风格编辑中的受支持属性 | 符号或注记外观，不移动城镇 |
| 改变道路经过的位置 | 要素编辑 | 真实路径及相关连接数据 |
| 调整道路线宽、颜色或虚线 | 风格编辑 | 交通线外观，不改变路径 |
| 把区域划给另一国 | 要素编辑 | 土地归属、国界与必要关联 |
| 改变国家填色 | 风格编辑 | 填色外观，不改变领土 |

- 工具名称、控制点和属性面板明确表达正在修改位置、归属还是外观。
- 标签、符号和领域位置的交互目标不能混淆；调整文字外观不触发城镇移动，选中显示国界也不自动修改领土。
- 表中外观能力以当前 Style Spec 实际支持为准，不因操作分类而额外承诺逐对象标签偏移等尚未支持的能力。

### 6.2 国家领土与国界

- 首版采用领土笔刷：选定国家，把区域划入该国，或将其移出并设为无主。
- 预览显示被修改区域、原归属和目标归属；海洋不可划为国家领土，湖泊按现有领域契约处理。
- 国界线和国家填色依据更新后的土地归属共同生成，面积和相关统计同步变化。
- 首版不承诺任意拖拽国界顶点形成亚网格边界；后续如提供此工具，必须同步更新权威领土表达。
- 对受影响城镇与人口分组的政治归属定义一致更新规则，人口总量、文化、族群与宗教不因划界自动改变。
- 首都必须仍合法归属本国；首版遇到划出首都、使国家失去有效领土等冲突时阻止应用并提供定位。
- 领土变化引起国家规模、领土特征或政体约束冲突时，列出问题；首版可阻止应用，不静默替换政体。
- 迁移首都可作为后续独立操作，不作为首版领土笔刷的隐含功能。

### 6.3 交通线

- 首版可选择已有道路或航线，查看端点、运输方式及路径。
- 通过增加、移动和移除途经点调整路径；途经点是用户指定的路径约束，最终路线由领域规则确定。
- 保持已有起讫聚落身份；不允许为了贴合绘制曲线而静默移动城镇。
- 显示吸附、路径预览、不可达区段及失败原因。
- 不同运输方式遵守各自通行条件，陆路、河运和海路不能只靠改变线条颜色互换。
- 合并绘制的共享路段应可定位到底层具体路线；应用时展示受影响路线，避免误改所有重叠交通线。
- 成功应用后路径、连接、距离或通行成本等已存在的相关字段同步更新。
- 仅改变线宽、颜色或虚线等已支持样式属性的需求由风格编辑处理；移动线路改变真实路径。渲染曲线的平滑不等于修改道路走向，也不自动成为首版风格属性。

### 6.4 城镇位置点

- 首版支持选中已有城镇、改名，以及拖动或点选新位置。
- 位置吸附到当前领域模型支持的区域，显示最终落点及所在区域；首版不新增亚网格聚落坐标模型。
- 目标位置需要满足海陆、湖泊、占位及现有聚落合法性约束；不支持的位置明确拒绝。
- 移动后保留城镇身份和人口，起讫区域总人口与人口分组按一致规则同步转移，世界总人口守恒。
- 跨国移动或改变首都归属涉及额外语义，首版可阻止并说明原因；不自动改变国家首都或政治归属。
- 关联交通线路必须完成必要更新；无法重连时展示冲突并阻止应用，不能发布悬空引用。
- 名称、符号、人口资料、探测信息与关联线路在应用后同步更新。
- 创建、删除城镇及主动修改人口规模属于后续扩展。

## 7. 风格编辑器（ED-STY）

### 7.1 文档与编辑入口

- 从当前样式建立可编辑副本，提供样式名称和未保存标记；内置预设作为可恢复起点保留。
- 使用项目现有 `MapStyleDocument`，当前 `version: 1`；支持范围以现有规范和编译器为准。
- 提供可视化属性面板与 JSON 编辑两种入口，共同编辑同一份样式草稿。
- 正在输入但不合法的 JSON 原文可暂存；只有校验通过的版本才能同步到属性面板并用于地图预览。
- 切换入口不能丢弃规范支持但可视化面板未覆盖的字段或表达式。

### 7.2 可视化编辑

| 分组 | 首版能力 |
| --- | --- |
| 文档 | 名称、说明、背景等已支持的全局样式项 |
| 图层 | 查看、选择、在允许的渲染分组内排序，调整默认启用状态 |
| 面与栅格 | 已支持的颜色、透明度、色阶等属性 |
| 线 | 已支持的颜色、线宽、透明度与虚线等属性 |
| 点与符号 | 已支持的尺寸、颜色及符号属性 |
| 文字 | 已支持的文字颜色、大小、描边与字体引用 |
| 显示条件 | 已支持的视图范围、缩放范围与过滤条件 |
| Tokens | 查看并编辑共享 token，预览受其影响的图层 |

- 图层按 `raster`、`fill`、`line`、`circle`、`symbol` 的实际类型提供适用控件。
- 排序遵守 `base`、`thematic`、`overlay` 及实际渲染约束；无法兑现的顺序不显示为成功。
- 区分图层当前临时开关与样式默认启用设置，用户明确选择是否把当前可见性保存为默认值。
- 已使用表达式的属性不能因打开面板自动变成常量；以常量替换时明确告知会替换原表达式。
- JSON 入口允许编辑现有规范支持的图层定义、表达式和数据源引用；新增图层仍只能引用当前可用且兼容的数据源。
- 外部数据源、任意脚本、扩展表达式运算符和字体上传不属于首版。

### 7.3 校验、预览和恢复

- 编辑合法属性后实时预览，连续输入可合并刷新；样式修改不触发世界重新生成。
- JSON 语法或样式编译失败时，显示错误位置、字段路径和可理解的原因，保留最后有效地图预览。
- 校验图层 ID、数据源、几何类型、属性类型、表达式、token 和已有规范要求。
- 样式涉及未生成的文明或资源时，说明图层当前无数据；不伪造要素，也不把整个样式判为损坏。
- 图例按当前有效样式同步；2D 与 3D 按样式声明的视图范围生效。
- 支持放弃草稿、应用样式、复制自定义样式及恢复到编辑起点。
- 自定义样式可独立导出、导入，往返后保留全部受支持字段及表达式。

## 8. 草稿、应用与操作历史（ED-HIS）

### 8.1 状态与提交

- 工作区区分“已发布世界/已应用样式”“当前草稿”“最后保存版本”。
- “预览”展示尚未应用的草稿；“应用”将通过校验的草稿变为当前有效世界或样式；“保存”将已应用成果导出到可恢复档案。
- 独立显示“有未应用修改”和“有未保存修改”，允许两种状态同时存在；应用、关闭编辑器或退出预览均不自动视为已经保存。
- 预览可以使用草稿，但必须标识状态；普通查询与统计不得混用新旧事实。
- 只有存在变化时才启用应用；提交前展示必要影响和冲突。
- 切换编辑器前处理当前草稿：应用、放弃或返回；不同时维护多个相互依赖的隐藏世界草稿。
- 耗时提交期间禁用冲突修改，保留导航浏览和取消能力。
- 草稿绑定目标世界身份。若世界被重新生成、导入或替换，旧草稿不得提交到新世界。
- 新生成或导入前说明未保存成果的处理；用户取消替换后继续编辑原世界。

### 8.2 撤销与重做

- 草稿阶段按有意义的操作撤销：一笔地形/领土笔刷、一次城镇拖动、一次线路调整或一次属性编辑。
- 连续颜色滑杆或数值拖动合并为一个操作，输入框使用正常文本撤销行为。
- 一次“应用”中的所有关联变化组成一个已提交事务；应用后的撤销恢复整个事务，不留下半完成状态。多笔统一应用时，界面说明本次包含的笔画数量和应用后整批撤销的粒度。
- 当前存在草稿时，撤销和重做作用于草稿；无草稿时作用于当前世界会话按时间排列的已提交操作。
- 新操作发生后清除相应重做分支，界面显示可撤销/重做的操作名称。
- 世界事实的撤销和重做仍需形成有效的新快照；风格撤销和重做仅更新样式状态。
- 建议提供 `Ctrl/Cmd + Z` 和 `Ctrl/Cmd + Shift + Z`，输入控件获得焦点时优先使用文本编辑行为。
- 首版不要求导入或重新打开文件后恢复完整撤销栈；保存当前成果不能依赖撤销栈。

### 8.3 异常和性能

- 校验失败、重算失败、地图准备失败或取消时保留上一次有效世界，并保留可恢复的草稿。
- 不允许原地写入已发布事实造成地图和缓存读数不一致。
- 高频指针事件仅更新交互预览，不逐事件执行完整快照复制、全量校验和地图重建。
- 应用时展示关联更新进度；计算期间可继续安全的地图浏览并可取消，不能同时进行冲突编辑。
- 取消后或目标世界已变化时，迟到的计算结果不能重新应用；取消不应导致原有效世界或已完成草稿消失。
- 内存或计算预算不足时给出可执行提示，允许缩小操作范围、取消或导出已有成果。
- 不将历史生成耗时视为编辑性能结论；交付时分别实测预览、应用和恢复，在 L6/L7/L8 记录配置、耗时和峰值。

## 9. 保存、导入与成果恢复（ED-SAVE）

- 提供导出当前编辑成果和导入恢复的用户入口；风格同时支持独立 JSON 导入导出。
- 世界成果保存编辑后的实际事实、有效身份和版本、必要的内容依赖、生成来源与人工修改来源，以及当前使用的自定义样式或明确的样式关联。
- 同时存在未应用草稿时，导出前明确选择应用草稿或仅导出已应用成果；导出不得把未校验草稿当作有效世界。
- 具体文件封装和版本方案在技术设计中确定；不将现有 M0 JSON 档案直接宣称为已经包含样式或编辑历史的项目格式。
- 导入先完整验证，再切换世界和样式；不兼容或文件损坏时保留当前工作区。
- 恢复结果不依赖再次运行当前版本生成器；相同 Seed 和参数不足以恢复人工修改。
- 原有生成参数分享链接仍用于分享生成输入，不能表示已包含编辑成果。
- 首版不依赖 IndexedDB/OPFS 或自动保存，但刷新、关闭或替换世界前应对未保存成果提供平台允许的提示。
- 保存提示须说明导出的是已应用成果，以及是否包含当前自定义样式；未支持持久化的工作区状态不得标记为已保存。

## 10. 数据一致性与实现边界

本节约束实现结果，不指定完整模块设计。

1. 世界事实由 `world-core` 受控修改、校验和发布；`apps/web` 负责交互、编排和存储；`cartography` 负责只读显示与编辑预览；`world-data` 继续负责候选内容。
2. 地图几何和 GPU 数据是派生结果，不能作为国界、交通或城镇事实的唯一修改来源。
3. 每次世界事实应用、撤销和重做形成新的快照身份与递增版本，查询、数据源和统计切换到同一版本。
4. 提交时核对草稿基于的世界身份，防止旧编辑覆盖新生成或新导入的世界。
5. 地形重算要明确读取人工修改及其签名；现有生成缓存和强制重算不能自动替代此能力。
6. 世界不变量始终成立，包括海陆一致性、有效引用、人口与人口分组守恒、聚落人口约束、交通有效性及国家首都和内容约束。
7. 生成目标与编辑后的有效性要求需要明确区分。后续增删国家不能仅通过篡改原始生成配置绕过国家数量校验。
8. 人工修改来源与生成来源应可区分；对象改名、移动保持稳定身份。
9. 风格和显示状态不改变世界事实，不进入自然或文明生成签名；编辑专用的视图、专题、透明度和高亮覆盖与样式草稿分别管理，退出时不会丢弃已应用样式。
10. 领域或公开数据契约确需变化时，再同步相应文档和档案版本；本需求草案本身不改变当前契约。

## 12. 建议交付顺序与待细化项

### 12.1 建议交付顺序

1. 编辑入口与二级菜单、等距圆柱工作视图、自动工作图层及退出恢复、公共面板状态、草稿和历史的最小闭环。
2. 风格编辑器，以及城镇/国家改名等简单要素操作，验证应用、撤销和导出流程。
3. 等距圆柱投影下的国家领土笔刷、交通线改线、城镇移动及关联规则。
4. 等距圆柱投影下的地形抬高/降低、稳定色阶与数值反馈、关联更新、冲突预览与取消恢复。
5. 联合保存恢复、其他投影和 3D 的一致预览、失败场景和高等级性能验收。

这是实施顺序建议，不改变第 3 节的首版目标。首版全部验收前，不把菜单可见或部分工具可用标记为完整编辑器交付。

### 12.2 技术设计需要进一步细化

- 笔刷参数范围、默认值、时间累计方式与网格尺度反馈。
- 各编辑器工作图层的实际映射、临时显示覆盖和浏览状态恢复策略。
- 跨视图取景尺度转换、日期线范围拆分与高纬度笔刷投影。
- 稳定绝对高程色阶、超范围反馈、变化量预览和草稿晕渲的具体实现。
- 城镇迁移时人口分组的准确转移规则，以及交通重连范围。
- 领土变化时政治归属和国家规模的更新规则与冲突文案。
- 地形下游需要重算的字段清单、保留文明的校验策略及计算预算。
- 当前编译器可视化编辑属性清单、图层排序实际能力和表达式编辑方式。
- 成果文件的封装、版本、样式关联及人工修改来源记录。
- 历史记录的内存上限、草稿预览策略和高等级性能目标。

以上内容需要在对应工具实现前形成可验证规则；未解决的领域冲突采用明确阻止提交的行为，避免隐式修改用户世界。
