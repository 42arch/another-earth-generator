# M1.2 C0 气候与环流校准

默认对照为 Seed 1024、L7、网格扰动 0.75、倾角 23.5°、降水倍率 1.8。使用同一份 `terrain-v25`，比较 `climate-c0-v2` 与 `climate-c0-v12`。数据按面积加权，年度风流向量是 12 个等时长月的分量平均。风流强度为模型相对值。

## 月度与空间验收

- 固定地形的逐项试验中，关闭压力驱动风分量后，v3 参考网格陆地年降水从 646 降到 591 mm；固定 ITCZ 后陆地月雨平均绝对差约 13.0 mm。该试验保留其他强迫，不能将各项差值直接相加。
- 以 1991–2020 NOAA PSL NCEP/NCAR R1 的 2 米气温和 10 米纬向风、GPCP v2.3 的月雨率作共同期分带对照。GPCP 雨率乘以等时长月份天数，海陆使用最近 NCEP 掩码。观测全球年均温约 14.20 °C，全球/陆地/海洋年降水约 983/790/1059 mm。默认样本全球量级明显接近，南半球热带海洋仍偏湿，部分中纬海洋偏干。地球和生成世界的大陆、海拔与极区覆盖不同。[NOAA PSL NCEP/NCAR R1](https://psl.noaa.gov/data/gridded/data.ncep.reanalysis.html) · [NOAA PSL GPCP](https://www.psl.noaa.gov/data/gridded/data.gpcp.html)
- 默认及三个独立复验 Seed 的南北 30–45° 海域，查询风与输送风的带平均东西分量均为 12/12 月东向。默认样本的热带海洋雨量纬度重心北移峰值从 6 月移到 8 月，与 GPCP 同月。逐月重心平均绝对差从 4.26° 降到 2.05°。两者比较使用 20°S–20°N 海洋降水的面积加权纬度重心。
- [NOAA/AOML 漂流浮标月气候](https://erddap.aoml.noaa.gov/gdp/erddap/info/drifter_monthlymeans/index.html)按 1° 抽样验证洋流方向，作为 OSCAR 的替代参照。默认世界出现年度东向的赤道窄带，南北热带西向主流保留。地球样本的 5–10°N 东向面积约 75%，模型的逆流主要在赤道附近。洋盆回流路径仍受经验分带约束；绕极通道和隔陆输热通过合成夹具验证，全球洋盆闭合流线与真实流速仍缺定量验收。
- [空间抽查图](M1.2-climate-calibration-atlas.png)显示默认气温纬度梯度、热带和中纬雨带、山地影响与分布相应的分类斑块。洋流在大陆边缘转向，并保留明显的纬向条带。图片使用 2° 最近网格采样，统计来自完整 Mesh。

## 实现与验证

先修陆地专用气温直减率和同水体洋流采样，再收窄海洋压力带及输送背景风的季节位移，增加海洋雨带的热惯性。洋流以连通绕极路径判定通道，宽洋盆的窄幅赤道逆流参考年平均热带辐合带，冷暖代理沿当前流向在水体内做有界输送。重新分配热带和中纬降水，并减弱极干内陆局地水汽补给与冻土蒸发。使用旧随机流键隔离版本变更对风噪声的影响。

保留 `feat-society` 的 Köppen/E0 分类规则、12 个等时长月、参考网格与 C0 依赖关系。三源温雨投影继续逐月校正全球雨量体积。热输送为沿流向的冷暖异常代理，使用参考网格边数作为距离尺度。

- 用相同 Mesh 逐格复算旧、新分类。43.60% 的陆地面积改变 Köppen 亚型，37.80% 改变 E0 群系。默认 `Af` 为 3.16% → 5.83%，新增的 2.70 个百分点中，2.69 个百分点来自跨过最干月 60 mm。 `EF` 和 E0 冰原为 2.49% → 3.87%，E0 热带雨林为 3.97% → 6.70%。这些是输入校准引发的变化。
- I0/H0 在相同 T0 上重算，陆地年均融雪 15.65 → 22.05 mm，12 月末积雪面积 24.97% → 32.78%，年均径流 323.11 → 400.64 mm，河段 1098 → 1109。真实 Worker 同时覆盖 I0/H0、L1 和 E0 的消费链路。
- Seed 42/314159/8675309、L6 的年均温为 15.27–15.44 °C，陆地年降水 733–841 mm。四个样本的最干月均出现 0 mm，海洋采样缺测与陆地洋流均为 0 面积。跨 Seed 的干旱强度与大陆布局变化，陆地年降水 P01 约 3–74 mm。
- 同机 Seed 1024/L6–L8 强制复算，月温、月雨、风与洋流的东西分量、暖度和新映射哈希一致。缓存复用覆盖全部 Stage，仅改变气温偏移时只重算 C0。L7 冷生成约 3.93 → 4.26 秒，L8 约 10.75 → 11.65 秒。L8 C0 数组约 76.02 → 78.64 MB，新增 2.62 MB 为输出洋流索引。整组进程峰值 RSS 约 1.8 GiB，单次采样供对照。
- 全仓 `pnpm test` 通过 180 项，全仓 typecheck 和 build 通过，真实 Chrome Worker 回归 10/10。新增或改动的 Core 气候代码与基准通过定向 lint。Web 全包 lint 的 75 处格式问题已与任务开始前的暂存内容逐文件对照，计数一致。

统计、逐月分带、逐格分类迁移摘要和性能原始值见[校准数据](M1.2-climate-calibration.json)。
