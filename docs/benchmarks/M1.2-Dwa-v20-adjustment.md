# C0 v20：东岸冬干大陆性气候扩展

2026-11-12。对比相同 Mesh、T0、配置与 Seed 下的 C0 v19 和 v20 面积加权输出。默认参数为半径 6371 km、倾角 23.5°、降水倍率 1.8；Seed 1024 使用 L7，其他三个 Seed 使用 L6。诊断命令为 `node_modules/.bin/jiti packages/world-core/benchmarks/climate-default-diagnosis.ts <seed> <level>`。百分比均以陆地面积为分母。

## 调整

用户反馈 v19 的 Dwa 仍太少。四 Seed 诊断显示，主要限制是 Dwa 所需的炎夏、冬季少雨条件重合范围有限。v20 做三项局部调整：东岸季风暴露区的附加温差振幅上限由 3°C 调至 5°C，作用按暴露度平方集中在东岸，并按西岸海洋影响衰减；冬季离岸气流对月雨的抑制系数由 0.82 改为 `0.82 + 0.16 × eastMonsoonExposure²`，只在冬季离岸气流起作用时生效；东岸季风暴露度向陆地传播的 e-fold 距离由 850 km 调至 1100 km。分类阈值与年温基线公式不变。

试验过 10°C 温差上限，默认 Dwa 可达 0.45%，但新增 Dwa 格最热月均值约 30°C，偏热；因此采用 5°C 上限。冬季雨量抑制也仅随东岸暴露度增强，没有全局调干。

还测试了仅增强东岸夏季季风降雨。Dwa 变化不一致（四 Seed 中三个小幅增加、一个略降），Cwa 增加 0.23–0.34 个百分点、BS 减少 0.09–0.35 个百分点；对扩大 Dwa 的帮助有限，因此没有纳入 v20。

默认 Seed 的 Dwa 从 0.081% 增至 0.266%，约为原来的 3.3 倍；其余 Seed 也都增加，范围变为 0.086%–0.169%。默认东岸温带低地 Dwa 集合约 113 个 L7 网格、占陆地 0.227%；最热月平均约 25.6°C、最冷月平均约 −3.3°C，冬季最干月与夏季最湿月之比约 0.055。增量仍集中在东岸低地，没有把整个中纬带都变成冬干大陆性气候。

默认 BS 增加 0.40 个百分点，仍有草原偏多的倾向；BW 基本稳定。Csa/Csb 的变化分别小于 0.1 个百分点。按 Seed 看，半干旱草原变化为 +0.11–0.40 个百分点；这项调整不会单独解决草原比例问题。陆地年雨量面积加权结果变化很小，四 Seed 约增加 1.0–1.7 mm/年。
