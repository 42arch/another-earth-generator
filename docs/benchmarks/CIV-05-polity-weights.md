# CIV-05 政体候选权重

2026-11-23。内置中英文政体包 `1.3.0 → 1.4.0`；核心算法 `polities-religions-v15`、WorldSnapshot Schema 11、分享 v15 均不变。本次只调整内容权重及特征偏好，不改变国家数量、领土扩张或特征形成公式。

## 问题与决策

20 种候选之前基础权重全为 1，通用的王国、共和国与军事执政团、保护国等特殊形态等权。多数君主政体没有对 `dynastic-aristocratic` 加权，王朝制君主国还在 `democratic` 下乘 0.45；公民议政与君主身份可以共存，不应以此自动压低君主形态。

修改前实际 Web 默认配置（Seed 1024、L7、扰动 0.75、气候倾角 23.5°/降水 1.8、近代工业商贸）并非没有君主政体：60 国中共有 17 个，但王国仅 2 个，王朝制君主国为 0。此处以继承性称号家族作诊断分组：王国、王朝制君主国、帝国、公国、埃米尔国、苏丹国、汗国；不把所有 hereditary 候选（如酋长领）都计入。这是内容分类口径，不是历史制度统计。

新权重是明确的内容先验：通用国家形态高于特殊形态，特殊候选依靠相关地理与国家特征获得优势。权重不是最终出现比例，也不是从真实国家样本拟合的频率；不设置全世界君主/共和配额，不按当前 Seed 缺什么强行补齐。
