# 默认参数 C0/E0 气候与群系诊断（2026-11-12）

本记录只定义本轮**诊断参照**和修改优先级，不改变 PRD 的产品规则，也不把 C0/E0 视为最终气候或植被。可复现命令：

```sh
node_modules/.bin/jiti packages/world-core/benchmarks/climate-default-diagnosis.ts > docs/benchmarks/M1.2-climate-default-diagnosis.json
```

输入为 Web 默认 Seed `1024`、L7、扰动 `0.75`、海平面基准 0 km、半径 6371 km、倾角 23.5°、降水倍率 1.8，其他参数用当前 Core 默认值。输出版本：T0 `terrain-v25`、C0 `climate-c0-v2`、E0 `ecology-e0-v2`。所有比例与均值按 Mesh 区域实际面积计算；原始逐纬度带、海拔带、分位数和类别面积表见同名 JSON。此次运行的是诊断脚本，未运行 test、build、lint、typecheck 或浏览器回归。

## 诊断参照

## 本轮结果与定位

- 面积海陆比例 29.90% / 70.10%；年均气温全域 17.03 °C、陆地 13.99 °C、海洋 18.33 °C。陆地 20–30 °C 占 38.84%，低于 0 °C 占 13.33%。陆地年降水 645.69 mm，海洋 1111.94 mm，全域 972.53 mm；全域总量接近参照，但海洋偏多、陆地偏少，故不能用统一降水倍率修复。
- 陆地年降水面积分位数为 P01 93、P05 154、P50 492、P95 1878、P99 2417 mm；低于 50 mm 的陆地仅占 0.006%，年降水最低 49 mm。`monthly-precipitation-generator.ts` 的陆地局地水汽补给存在正下限，传播又用 `max(localSupply, carried)`，这与极干尾部缺失一致；是否还存在其他限制需在改动前用分量诊断确认。
- 海洋最高年均气温 40.74 °C。该区域输出海底高度 -2.87 km、所用参考高度约 -0.92 km，`projectClimateC0` 对二者应用 `-6.2 °C/km` 的高程修正，单点增加 12.08 °C；去掉这项的诊断值约 28.67 °C。海洋这项修正面积加权净值仅 +0.009 °C，所以它是局地错误，不是全球 +2 °C 的解释。下一步应只对陆地使用高度差温度修正，并单独复核海洋温度场。
- 陆地纬度分布影响年均温：南纬 60°以南占本世界陆地约 6.26%，北纬 60°以北仅约 3.70%；南纬 75°以南仅 0.50%。南纬 75°以南陆地年均 -13.6 °C。地球南极冰盖接近 1400 万 km²，约占全球陆地一成；南极沿海到高内陆的年均温约 -10 至 -60 °C，当前默认世界缺少大面积极冷高纬陆地。[NSIDC 冰盖面积](https://nsidc.org/ice-sheets-today/about-project)、[英国南极调查局气温](https://www.bas.ac.uk/news/signy-island-is-hottest-place-in-the-antarctic/)。随机世界无须复制南极大陆，但默认类地球的陆地均温与冰原面积不能只靠温度常数校准。
- 陆地海拔 0–1、1–2.5、≥2.5 km 的面积占比分别为 75.34%、16.91%、7.75%；对应年降水均值 743、397、242 mm。高地普遍偏干可能来自高原内陆、参考网格聚合及抬升/雨影项共同作用；仅凭平均值不能断定应削弱雨影。
- E0 面积分类：草原 `Steppe` 28.19%，热/冷荒漠合计 8.77%，`IceSheet` 2.49%，热带雨林 3.97%。C0 的 Köppen `EF` 同为 2.49%。地球现存冰川冰盖约覆盖 10% 陆地，[NSIDC](https://nsidc.org/ru/node/21548)；E0 潜在群系与实际冰盖口径不同，此差异先用于追踪极地地形与气候输入，不直接按比例强制分配群系。

## 月度数据补充诊断

最初记录只有逐月的全陆地、全海洋面积平均。现已补齐南北半球和 15° 纬度带的逐月气温/降水，以及每个陆地区域的最冷/最暖月、最干/最湿月、季节温差、夏半年降水占比、低温和少雨月份数。原始逐月表在 JSON 的 `monthlyByHemisphere`、`monthlyByLatitude`、`landMonthlyIndicators`、`monthlyThresholdLandShares` 字段。

- 全陆地月均温仅在 13.6–14.3 °C 变化，这是南北半球相反季节抵消的结果。北半球陆地 1/7 月分别为 6.7/24.4 °C，南半球陆地为 21.5/2.1 °C；纬度带的最暖月也随半球反转。逐格陆地最暖月与最冷月温差的面积中位数为 19.54 °C，P95 为 29.46 °C。季节相位存在，但温差是否接近地球仍需同纬度观测对照。
- 全陆地月降水约 48–63 mm，看不出分带季风。北半球陆地 1/7 月为 32/94 mm，南半球陆地 1/12 月为 68/71 mm、7 月 28 mm；分带数据更能反映季节迁移。陆地“当地夏半年”降水占比面积中位数为 64.69%，P05/P95 为 31.67%/85.17%。这些是当前世界的内部诊断，尚未与 GPCC 同尺度月气候对齐。
- 逐格陆地最干月降水最小 1.53 mm、面积 P05 4.95 mm、中位数 16.81 mm；没有任何陆地的最干月低于 1 mm。29.74% 陆地的最干月低于 10 mm，95.96% 低于 60 mm。全年雨量最低 49 mm 和月度正下限共同指向极干尾部缺失。此处仍须区分陆地局地补给、湿度传播和投影各自的影响。
- Köppen `Af` 使用“12 个月气温均 ≥18 °C 且最干月降水 ≥60 mm”。全年温暖陆地占 18.93%，其中仅 16.68% 达到最干月门槛，乘积为陆地 `Af` 面积 3.16%。E0 热带雨林另外要求年降水 ≥1700 mm 且最干月 ≥45 mm；全年温暖陆地中 20.99% 同时满足，两者乘积为陆地雨林 3.97%。因此雨林偏少首先要检查月降水的空间分配与旱季幅度，不能只看年总量或直接改 E0 分类阈值。
- Köppen `EF` 和 E0 `IceSheet` 都占 2.49% 陆地，与“最暖月仍低于 0 °C”的陆地面积完全一致。南纬 60°–75°陆地的逐月带均温在 -19.7 至 7.8 °C，许多地区夏季越过冰原阈值。分类器按现有规则工作；极地面积和月温场是当前主要待诊断输入。

月度输出已与 C0/E0 的实际阈值对应，但尚未完成观测月度场重采样、多 Seed 和雨影专项验证。上述关联不是对公式贡献的完整因果分解。

## 修改顺序

1. **修复局地明确错误**：海洋投影不使用海底深度作为气温直减率；在固定 Seed 和不同分辨率上核对海洋极值、均值、海岸过渡及 Köppen/E0 下游变化，并升级 C0 Stage 版本。
2. **分解陆地偏暖来源**：按纬度和海拔对照类地球参照；先区分默认地形的高纬陆地不足与同纬度气温公式偏暖，再决定改 T0 地理分布还是 C0 热力项。不要先施加全域温度偏移。
3. **重分配降水并恢复尾部**：保留全域水量量级，检查海陆水汽输入/输送、局地补给下限、抬升与雨影；补极干和极湿区域的同尺度面积分布比较，再调整公式。不要直接上调全域 `precipitationScale`。
4. **最后复验分类**：用同一批 C0 月值重新统计 Köppen、E0 群系和自然覆盖的面积占比、纬度与相邻关系，确认类别变化可由气温/降水解释。E0 本身的阈值调整应在输入气候稳定后进行。

仍缺：多 Seed、L6/L8 稳定性、观测网格重采样后的同尺度分位数、雨影合成夹具和空间图像复核。因此这里的范围是诊断目标，不是已通过验收。
