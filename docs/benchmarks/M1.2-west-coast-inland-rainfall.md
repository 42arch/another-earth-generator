# C0 西岸夏雨与副热带内陆输送校准

`climate-c0-v13` 在夏季用既有副热带高压强度和西岸暴露度削弱锋面雨项。暖干内陆的水汽混合损失按风速修正传播时间，模型相对速度 1 对应原衰减尺度，弱风增加衰减，风速高于 1 时沿用原尺度。降水、气温和分类仍使用 12 个等时长月。分类阈值、风场随机流、风速显示换算和投影契约沿用原值。

## 输出网格

以 `terrain-v25`、扰动 0.75、倾角 23.5°、降水倍率 1.8 固定配置。下表为各版本陆地实际面积占比。

| Seed / 网格 | Cfa v12 → v13 | Csa v12 → v13 | BW v12 → v13 |
| --- | ---: | ---: | ---: |
| 1024 / L7 | 13.73% → 10.65% | 5.35% → 7.99% | 4.34% → 4.69% |
| 42 / L6 | 10.39% → 8.38% | 2.97% → 4.47% | 4.72% → 5.19% |
| 314159 / L6 | 12.83% → 10.53% | 2.63% → 4.63% | 2.74% → 2.92% |
| 8675309 / L6 | 16.26% → 13.21% | 4.32% → 6.62% | 2.39% → 2.54% |

默认样本全域／陆地／海洋年雨量为 **989.8／731.0／1100.2 → 985.3／716.0／1100.2 mm**，年均温约 **15.20°C**。归档与复算的年度及月度风、输送风、洋流和热带辐合带分组统计完全相同。默认 I0/H0/L1 与 E0 生成完成，陆地年均径流 **400.6 → 391.1 mm**，河段数均为 **1,109**。

## 同一参考区域的前后对照

在同一参考网格上用 v12 确定区域，再分别统计两个版本的温雨输出。朝东／西海岸组选南北纬 25°–45°、高程低于 1 km、邻接海洋且海岸朝向东西分量绝对值至少 0.25 的原 Cfa 网格。深内陆组选南北纬 15°–35°、高程低于 1 km、模型估算距海至少 900 km 的陆地。夏半年沿用分类器的北半球 4–9 月、南半球 10–3 月。雨量按区域面积加权。

| Seed | 原西岸 Cfa 夏半年雨量（mm） | 原西岸 Cfa 转为 Csa | 原东岸 Cfa 夏半年雨量（mm） | 深内陆年雨量（mm） |
| --- | ---: | ---: | ---: | ---: |
| 1024 | 383.3 → 285.5 | 53.0% | 470.2 → 458.5 | 331.5 → 316.3 |
| 42 | 426.8 → 323.6 | 43.7% | 473.1 → 462.4 | 302.9 → 298.8 |
| 314159 | 391.3 → 296.4 | 44.0% | 501.4 → 486.1 | 480.8 → 476.5 |
| 8675309 | 404.8 → 309.6 | 45.2% | 508.2 → 494.8 | 697.3 → 690.3 |

默认样本原西岸 Cfa 的冬半年雨量为 **512.5 → 504.7 mm**。同一默认参考内陆组的 BW 占比 **26.1% → 31.9%**。内陆样本仍受海岸与上风向几何影响，三个复验 Seed 的干燥幅度小于默认样本。该对照用于核验机制及影响范围，区域绝对雨量的观测验收另计。

默认输出统计和下游摘要使用 `climate-default-diagnosis.ts`、`circulation-default-diagnosis.ts` 和 `climate-downstream-screening.ts` 的独立诊断入口。逐区域对照使用同一 T0 和同一月度环流分别求解 v12/v13，分类调用现有 `classifyKoppenSeries`。历史 v12 全局基线见 [原校准数据](M1.2-climate-calibration.json)。本轮实际运行四个 Seed 生成诊断和默认下游诊断，新增两项降水回归用例，未运行 test、build、lint、typecheck 或浏览器检查。
