# C0 风速与表层流速的显示标定

速度估计采用 `hypot(east, north) × scale`，单位为 m/s，表示月平均向量的大小。拟合使用 `terrain-v25` / `climate-c0-v12` 默认 Seed 1024/L7，在南北纬 60° 之间每 15° 分带，取 12 个月共 96 组海域统计。每组按球面纬带面积加权，最小二乘拟合过原点的正比例系数，保留零值和向量方向。

- 风速使用归档的 NCEP/NCAR R1 1991–2020 年 10 米风，拟合海域带平均东西分量的绝对值。应用时东西、南北分量使用同一系数，陆地也沿用该海域系数。
- 表层流速使用归档的 NOAA/AOML 漂流浮标月气候，拟合海域带平均东西、南北分量合成后的大小。取样为 1° 间隔，仅纳入两个分量都有 12 月数据的格点。

观测与生成世界分别按各自的海陆掩码计算分带平均。拟合输入是分带聚合值。逐格速度分位数、陆地风、近岸峰值与高纬超出本次拟合范围，UI 中标注为估算。获取 NOAA 原始文件的自动权限审核超时，本次使用已归档的观测摘要。 [归档观测](M1.2-climate-calibration.json) · [NOAA 漂流浮标月气候](https://erddap.aoml.noaa.gov/gdp/erddap/info/drifter_monthlymeans/index.html)

| 量 | 默认拟合系数（m/s 每模型单位） | 显示系数 |
| --- | ---: | ---: |
| 10 米风速 | 0.256802 | 0.257 |
| 表层流速 | 0.097051 | 0.097 |

沿用上述显示系数时，分带比较的加权 RMSE 如下。风对应带平均东西分量绝对值，洋流对应带平均向量大小。

| Seed / 网格 | 风（m/s） | 表层流（m/s） |
| --- | ---: | ---: |
| 1024 / L7，拟合 | 1.439 | 0.041 |
| 42 / L6，复验 | 1.515 | 0.044 |
| 314159 / L6，复验 | 1.311 | 0.042 |
| 8675309 / L6，复验 | 1.483 | 0.042 |

复现命令从仓库根目录运行。

```sh
speed_fit_dir=$(mktemp -d)
node_modules/.bin/jiti packages/world-core/benchmarks/circulation-default-diagnosis.ts 1024 7 > "$speed_fit_dir/1024.json"
for seed in 42 314159 8675309; do
  node_modules/.bin/jiti packages/world-core/benchmarks/circulation-default-diagnosis.ts "$seed" 6 > "$speed_fit_dir/$seed.json"
done
python3 packages/world-core/benchmarks/circulation-speed-fit.py docs/benchmarks/M1.2-climate-calibration.json \
  "$speed_fit_dir/1024.json" "$speed_fit_dir/42.json" "$speed_fit_dir/314159.json" "$speed_fit_dir/8675309.json"
```
