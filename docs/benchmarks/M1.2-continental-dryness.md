# C0 大陆冬季与副热带背风干燥

`climate-c0-v15` 将已有冷空气衰减放入陆地间的输送路径，经过寒冷陆地的水汽随传播时间累积损失。冷空气仍由原温度响应和衰减尺度表征。暖干陆地的下坡路径增加背风干燥，沿用已有地形衰减尺度；局地雨影和迎风抬升继续使用原有计算。直接来自海洋的入流不承受这两项额外陆地衰减。Köppen 阈值沿用原规则。 [背风干燥机理](https://www.weather.gov/key/glossary)

在南北纬 40°–60°、低于 1 km 且距海 300–900 km 的低地，四个样本的 Dfb 占比分别减少约 3.7–9.7 个百分点。默认世界这组低地的 Dfb **42.89% → 33.72%**。逐格复算默认世界，原 Dfb 转为冷半干旱 BSk 和冬干 Dwb 的面积分别占全陆地 **1.02 和 0.35 个百分点**。在南北纬 15°–35°、低于 1 km 且距海至少 900 km 的低地，默认沙漠占比 **65.55% → 81.92%**。

默认全域／陆地／海洋年雨量 **977.2／688.8／1100.2 → 968.9／660.9／1100.2 mm**，全球年均温约 **15.18°C**。Af **5.53% → 5.42%**，Dfc **5.78% → 4.18%**。默认 I0/H0/L1/E0 生成完成，陆地年均径流 **370.5 → 355.1 mm**，河段数 **1107 → 1102**。面积结果用于比较同一生成世界的改变，区域绝对月雨量仍缺同地理条件的观测验收。 [v14 基线](M1.2-subtropical-desert.md)
