# C0 v17 西岸干夏范围校准

2026-11-12。延续 [v16 逐格核对](M1.2-Csa-v16-assessment.md)。固定物理半径 6371 km、Mesh 扰动 0.75、倾角 23.5°、降水倍率 1.8、T0 `terrain-v25`，其余 Core 默认参数。C0 的科本阈值、温度、风和洋流算法未变。

## 原因与改动

v16 默认 Seed 1024/L7 的 Csa 占陆地 7.70%，其中模型西岸暴露度 0.2–0.5 的 Csa 面积约 371 万 km²，0–0.2 约 229 万 km²。v13 加入的西岸夏季锋面雨抑制是扩张的主要可控贡献。四 Seed/L6 的单项消融如下；每项均从 v16 基线单独取消，结果不能相加。

| Seed / L6 | v16 Csa | 取消夏季锋面抑制 | 取消末端夏雨削减 | 取消冬季西风增雨 |
| --- | ---: | ---: | ---: | ---: |
| 1024 | 7.38% | 5.76% | 7.02% | 6.65% |
| 42 | 4.23% | 3.25% | 4.01% | 3.85% |
| 314159 | 5.05% | 3.75% | 4.58% | 4.46% |
| 8675309 | 7.69% | 5.85% | 6.99% | 6.81% |

v17 将西岸暴露度通过 `smoothstep(0.25, 0.8, westCoast)` 转为季节作用强度，替代三处季节项原先的线性暴露度；夏季锋面抑制幅度从 1 降至 0.5。高暴露西岸保留冬湿夏干信号，弱暴露沿岸获得更多夏季锋面雨。全域副热带高压、月度水汽输送、末端夏雨削减的最大幅度 0.3 与冬季增雨的最大幅度 0.65 不变。该参数选择来自四 Seed 消融和逐格暴露度分组，不将地球 Csa 约 2% 当作面积配额。

## 固定 Seed 对照

输出 Mesh 区域按实际 km² 面积加权。执行 `node_modules/.bin/jiti packages/world-core/benchmarks/climate-default-diagnosis.ts <seed> <level>`；默认下游使用 `node_modules/.bin/jiti packages/world-core/benchmarks/climate-downstream-screening.ts`。v16 基线见上述评估与 [陆地水汽再循环对照](M1.2-land-water-limited-recycling.md)。

| Seed / 等级 | Csa v16 → v17 | Csb v16 → v17 | Cfa v16 → v17 | BW v16 → v17 | BS v16 → v17 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1024 / L7（Web 默认） | 7.70% → **6.06%** | 1.01% → 0.56% | 8.68% → 10.43% | 9.84% → 9.76% | 23.22% → 22.95% |
| 1024 / L6 | 7.38% → **5.83%** | 1.03% → 0.69% | 8.80% → 10.54% | — | — |
| 42 / L6 | 4.23% → **3.51%** | 1.19% → 0.85% | 6.30% → 7.15% | 13.15% → 12.98% | 21.02% → 20.95% |
| 314159 / L6 | 5.05% → **3.94%** | 0.80% → 0.56% | 7.99% → 9.16% | 8.37% → 8.29% | 20.33% → 20.11% |
| 8675309 / L6 | 7.69% → **6.17%** | 0.54% → 0.41% | 9.68% → 11.10% | 10.09% → 9.91% | 19.97% → 20.08% |

默认 Csa 约 1174 万 → **924 万 km²**。按模型西岸暴露度分组，暴露度 ≥0.5 的 Csa 面积约 **464 → 440 万 km²**（−5.1%），0.2–0.5 约 **371 → 216 万 km²**（−41.6%），0–0.2 约 **229 → 165 万 km²**（−27.8%），暴露度恰为 0 约 **110 → 102 万 km²**（−7.1%）。收缩集中在弱至中等西岸信号区域，而不是典型强暴露西岸。分组暴露度来自参考 Mesh，距离是模型近似。

默认陆地年雨量 **649.9 → 658.6 mm**，全球 **965.6 → 968.2 mm**；陆地年均径流 **352.8 → 357.9 mm**，河段数仍为 **1,095**。Af 保持约 **5.42%**。E0 地中海灌丛占陆地 **5.56% → 4.04%**，温带季节性森林 **9.66% → 11.12%**，草原 **22.52% → 22.25%**，热／冷沙漠分别 **5.26% → 5.22%**、**4.42% → 4.40%**。`climate-default-diagnosis.ts` 的 E0 统计和 `climate-downstream-screening.ts` 的 I0/H0/E0 生成均完成；此轮没有单独复跑 L1、浏览器或完整自然快照链。

Csa 仍高于用户提供的地球面积参考；不同岸线几何使绝对份额不能直接等同。Csb 随干夏区收缩而减少，Cfa 增加，这是真实的类别迁移而非阈值改动。当前缺同尺度地球海岸形态和区域月雨观测对照，不能把剩余差额继续机械压低。若后续继续校准，应针对高暴露西岸及 Csb 的月雨分别验收。

版本从 `climate-c0-v16` 升为 `climate-c0-v17`，使旧 Stage 缓存及下游依赖签名失效并重算。字段、单位、分类阈值和公开接口不变。已添加弱暴露／强暴露的季节降水回归用例；按仓库要求，本次未运行 test、build、lint、typecheck 或浏览器检查，新增用例尚未验证。
