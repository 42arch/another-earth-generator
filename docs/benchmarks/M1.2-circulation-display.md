# C0 v22 环流重采样与显示色阶

2026-11-20。目标是改善风速、表层洋流速度的参考网格块状边界和颜色层次，不改变参考网格上的风、洋流生成公式或物理标定系数。

## 处理规则

- 风从最近参考格及其一环邻域选择最多三个来源，优先同海陆类型，采用球面弦长平方反比权重。重合点精确保留原值。
- 洋流沿用最终网格上的连通水体映射。插值来源限制为映射中心及其直接相邻海水格，并且参考源必须归属于同一个最终水体。陆地、未被参考源覆盖的孤立水体继续缺测，不能当作静止洋流。
- 东/北分量先沿最短大圆平行移动到输出格的切平面，再按权重混合。经度接缝和极区不直接混合不同位置的局部坐标分量。反足点使用确定性的源东向旋转轴约定。
- C0 阶段产物新增可选 `projectedCirculation`，保存输出网格的五个四季字段。查询与月度发布共同读取这些字段。参考场保留用于诊断；温度、降水和 Köppen 的计算路径保持原样。年速度继续先逐月求模长再平均。
- 版本为 `climate-c0-v22`，风噪声仍用 v2 随机流键。旧阶段缓存失效；Schema 3 字段结构不变，旧快照按已有数据恢复，不在加载时重采样。

新增季节数组本身占 `80 × regionCount` 字节（L7 约 12.5 MiB，L8 约 50 MiB）；不保留每格插值权重或旋转矩阵。该数值仅是新增数组的理论字节数，不代表缓存副本、发布副本或进程峰值内存。L8 峰值和生成耗时未专项实测。

## 固定显示标尺

- 风速：`0 / 2 / 5 / 8 / 12 / 16 / 25 / 40 / 65`。原上限 12 m/s 约在 P90，扩大上段可区分强风；参考 Earth Nullschool 的深色天气图风格，使用深蓝→蓝青→青绿→黄绿→暖橙→红紫的连续过渡，去掉白色中点；颜色为项目内重新选取，并非网站原色表。
- 洋流：`0 / 0.03 / 0.055 / 0.08 / 0.10 / 0.14 / 0.21`。在常见的 0.04–0.10 m/s 加密断点，参考同站洋流图的深蓝底色与青绿高值，采用深蓝→蓝青→青绿→黄绿的连续过渡；有效零速、陆地和缺测分别处理。
- 月度和年度共用同一套绝对 m/s 色阶，六种预设共用；不按月份或当前世界自动拉伸。超过色阶上限仍显示末端颜色，统计保留 `≥` 桶。
- 地图表达式、提取的图例和统计使用相同断点；统计优先读取当前样式图例，并保留最多三位小数。图例渐变条按断点的数值位置排列，不再把不等间隔数值画成等间隔色标。

配色视觉参考：[Earth Nullschool](https://earth.nullschool.net/zh-cn/)。用户链接选择的是温度叠加；本次另行切换查看了风速与洋流色图。当前变更仅调整环流配色，不改变温度、降水、速度断点或空间渲染器。
