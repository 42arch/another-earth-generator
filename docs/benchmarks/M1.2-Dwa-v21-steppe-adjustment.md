# C0 v21：东岸季风区半干旱草原调整

2026-11-12。对比相同 Mesh、T0、配置与 Seed 下的 C0 v20 和 v21 面积加权输出。默认参数为半径 6371 km、倾角 23.5°、降水倍率 1.8；Seed 1024 使用 L7，其他三个 Seed 使用 L6。百分比均以陆地面积为分母。

## 调整与结果

用户提出适当减少草原、增加 Dwa 等气候类型。Köppen 分类依照年降水、季节雨量及月温判定；v21 提高强东岸季风暴露区的夏季迎风降雨增益，增益从 3.2 增至 `3.2 + eastMonsoonExposure²`。不直接改类别标签、干旱门槛或温度分类阈值。该改动使夏季季风降雨增加，为部分半干旱区域补充湿季降水，也让原有冬干类更容易满足冬季相对干燥条件。

四个 Seed 的半干旱草原都减少 0.09–0.35 个百分点，Cwa 都增加 0.23–0.34 个百分点。Dwa 在三个 Seed 增加 0.02–0.08 个百分点，在 Seed 314159 减少 0.01 个百分点；其面积仍取决于当地是否同时达到炎夏和寒冬条件。减少的草原会按月温和季节降雨条件转成不同气候类，主要增加的是 Cwa，并非都能成为 Dwa。默认 Csa/Csb 基本不变，BW 减少约 0.06 个百分点，默认陆地年雨量增加 2.77 mm/年。
