# CIV-03 国家数量与面积差异验收

2026-11-23，v13 验收记录。`polities-religions-v13`、WorldSnapshot Schema 10、分享 v15。本记录只覆盖国家数量与面积差异的创世行为，不是历史制度/面积分布校准或高等级性能结论。

> 当前 v14 的小面积政体约束及重新验证范围见 [CIV-04](CIV-04-polity-size.md)；本文保留 v13 当时的数据与验证结论。

## 参数与语义

`polityDensity` 移除，显式旧字段拒绝。替换为：

```json
{
  "polityCount": 60,
  "politySizeVariation": 0.5
}
```

国家数量是 1–200 的整数，默认 60。Web 使用一个滑杆，步长 1；选择多少就生成多少，包含岛国，不再随机抽取国家数。原先误实现的 min/max 区间对象已移除且显式拒绝。可用独立陆地聚落不足请求数时，错误包含实际可行数量，失败保留最后有效世界；无人口世界沿用空文明例外。

大陆与孤岛使用同一国家预算。先按人口覆盖可达片区，剩余首都用选址加权最远点补齐；不因间距不足少建国家，也不在划界后追加岛国。预算无法覆盖且不可跨海的地区可以无主，不强行生成交通能力。

四预设的国家数以默认 60 沿用 CIV-01 的数量比例：农耕 60、城邦商贸 108、区域王国 36、近代工业商贸 60。核心只读取整数，不读取预设 ID 或倍率。

面积差异为 0–1，默认 0.5：在每个有国家的可达片区保留首都格面积，剩余面积按 `rank^(-2*variation)` 份额分配；名次由稳定随机流与特征基础速率共同确定。0 为近均衡目标，1 为大小梯度。扩张按各国已占/目标面积调度，其内部前沿继续使用地理、文化、宗教和交通成本。湖面、海面不计国家陆地面积。孤岛、阻塞、首都位置、格网和后续投送使目标只具有引导作用，差异 0 也不保证全球等面积。

Schema 10 与分享 v15 明确拒绝旧 Schema 1–9 / 分享 v14 及更早版本，不迁移旧区间或倍率。

## 当前输入与复现

```sh
bun run --cwd apps/web bench:civilization:layout 6 exact 1024 42 m2-civilization-seed
```

内置生产内容、核心默认自然参数、地球半径 6371 km、输出 L6、扰动 0.45、参考 L6。此处核心自然参数不等于 Web 初始面板的全部默认值。除数量与面积差异外，文明参数为当前默认。完整配置、内容签名、版本和逐国面积见 [v13 原始结果](CIV-03-layout-exact-L6.json)。

每个 Seed 验证 5 组：60 国 × 差异 0/0.5/1，另加 1 国/0.5、200 国/0.5；每组均装配并执行完整快照校验。随后完整强制重算 60 国/0，比较逐格归属 SHA-256 和各国面积，避免仅以同样的汇总分布冒充确定性。

## 当前实测

15 组全部准确得到请求的 1、60、200 国。固定 60 国的实际面积分布：

| Seed | 差异 0 的 Gini | 差异 0.5 的 Gini | 差异 1 的 Gini |
| --- | ---: | ---: | ---: |
| 1024 | 0.372 | 0.615 | 0.799 |
| 42 | 0.288 | 0.612 | 0.837 |
| m2-civilization-seed | 0.322 | 0.584 | 0.713 |

三组世界的实际面积 Gini 与变异系数均随这三个采样点增大。没有按这些计数或比例回调参数；不保证所有 Seed 的每一步变化严格单调。低差异仍有孤岛小国及被地理限制的大国，体现了目标与实际可达面积的区别。

只改变面积差异时，首都与国家特征保持一致；改变数量或面积差异均只执行政体宗教阶段，上游全部缓存命中；人口总数在同一 Seed 的 5 组间完全一致。3 次完整强制重算均复现逐格归属与面积。
