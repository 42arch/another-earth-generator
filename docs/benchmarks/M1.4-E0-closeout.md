# M1.4 E0 当前自然链收尾核对（2026-11-12）

## 范围与修正

本轮 M1 采用 T0 `terrain-v25`、C0 `climate-c0-v16` 驱动 E0。I0/H0/L1 为并行水文产物，河流和静态湖泊不改写潜在生物群系或自然覆盖。E0 仍是 `GenerationArtifact`；发布世界、档案往返及失败保持属于 M1.5/M1.6。

核对时发现 `ecology-e0-v2` 从网格中心的 Z 分量读取纬度，而 C0/Köppen 及球面坐标契约使用 Y 分量。该错误影响南北半球夏季判断和高纬冰原判据。现改为 Y 分量并升级至 `ecology-e0-v3`，旧 E0 缓存随 Stage 版本失效；类别字典和公开字段未改。合成夹具分别覆盖高纬冰原和南北半球干夏分类。

四组雨林年雨量均值约 2,230–2,291 mm；热/冷荒漠各类均值约 155–228 mm，半干旱草原约 349–427 mm。雨林平均绝对纬度为 6.1°–7.8°，针叶林 52.5°–53.8°、苔原 63.2°–66.6°；默认冰原均值 54.0°，其余三组 67.6°–72.9°。默认冰原平均纬度较低，尚需结合海拔和月温判断局地成因，不能将分类面积直接解释为海平面冰盖。各样本有多个连片雨林、荒漠与冰原区；最大连片占本类面积的比例及组件数已归档。该证据支持分类与当前气候/地形输入的内部一致性，不以地球类群系面积配额作为生成约束。

四组海洋/陆地类别错误和潜在群系→自然覆盖映射错误均为 0。默认 Köppen BW 占陆地 9.84%，E0 荒漠 9.68%；EF 占 3.89%，E0 冰原 3.94%。两套分类规则不同，少量边界差异是预期结果。v2→v3 荒漠及雨林面积未变；冰原面积随纬度修正小幅增加。类别词表不含农田/城市，`SnowIce` 仍是气候代理，不是多年冰川体积。

同输入旧分类器回放另见 [v3 对照](M1.4-E0-legacy-comparison-v3.json)：Seed 42/L6、扰动 0.5、默认 C0 参数，11,954 个陆地区域类别差异为 0。此项仅验证分类数学迁移，使用当前 v25/v16 输入，不表示旧版气候场与当前场一致。v2 的历史回放保留在 [旧记录](M1.4-E0-legacy-comparison.json)，不可用于证明 v3 的纬度判断。

## 验证与界限

- Core 新增 E0 合成场景与 Stage 集成测试：2 文件、5 项通过；覆盖类别/自然覆盖、年度聚合与非法值、Y 轴纬度/半球、缓存命中及强制重算、水文 Stage 不进入 E0 计划。
- Web 定向单测：2 文件、17 项通过。真实 Chrome Playwright 两个定向用例均通过：默认 Seed 1024/L7 自动生成，以及 E0 生成、河湖解耦、群系/自然覆盖切换、区域查询与缓存命中；E0 用例在页面措辞调整后复验通过。Core 和 Web 包级 typecheck 通过；新增 E0 诊断/测试文件的定向 ESLint 通过。扩大到本次涉及的所有源码和基准文件时，ESLint 仍报告既有格式问题；未对无关行批量格式化。
- 本轮 E0 分类和链路按 **T0/C0 初步模型范围**收尾。尚无真实植被分布观测同尺度标定；地球的群系面积不作为这些不同海陆 Seed 的通过门槛。逐月土壤水、永久冰盖、湿地和水生生态分类不在本轮 E0 模型内。完整自然快照与 M1 整体验收仍待 M1.5/M1.6。
