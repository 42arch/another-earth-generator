# C0 v18 西岸夏温与 Csa/Csb 校准

2026-11-12。固定 T0 `terrain-v25`、物理半径 6371 km、Mesh 扰动 0.75、倾角 23.5°、降水倍率 1.8，余项取 Core 默认参数。v17 的 [西岸季节降水校准](M1.2-Csa-v17-adjustment.md) 降低了 Csa 面积，却也把 Csb 从默认陆地 1.01% 降至 0.56%。本轮只调整月温的西岸海洋性年温差；科本阈值、降水项、风场和洋流未改。

## 机制与方案筛选

原月温公式即使在最靠海的陆地，仍使用明显大于海洋的季节振幅。副热带西岸受海洋影响时，夏季月均温应更温和；NOAA 记录西岸夏季冷水上涌可冷却邻近海面并影响沿岸气候，但当前模型**没有显式模拟上涌**，因此这里仅校准海洋性年温差代理。[NOAA 沿岸上涌说明](https://oceanservice.noaa.gov/education/tutorial_currents/03coastal4.html)

把西岸陆地季节振幅全纬度混合到海洋值的初案，使默认 Csa/Csb 为 4.63%/1.95%，但 Dfb 10.57%→7.79%、EF 3.88%→4.86%，影响过广，未采用。最终用既有 `westCoastInfluence` 乘以绝对纬度窗：22°–30° 平滑开启，42°–52° 平滑关闭；据此在陆地振幅与海洋振幅之间插值。强暴露副热带西岸的夏季降温、冬季升温，年平均温度近乎不变；内陆、东岸与极地保留原振幅。纬度窗限定了当前 Csa/Csb 主分布带，防止全纬度初案扰动 Dfb/极地；窗的端点来自本轮四 Seed 与默认纬度诊断，不是 Köppen 分类阈值。

默认新 Csb 的 **78.7%** 位于模型西岸暴露度 ≥0.5 的区域；**98.0%** 位于绝对纬度 30°–50°，其中 43.6% 位于 30°–40°、54.4% 位于 40°–50°。Csa/Csb 面积比从约 10.9 降至约 2.4，变动主要体现为西岸热夏转暖夏。默认 Dfb **10.57%→10.08%**、EF **3.88%→3.95%**，比全纬度初案的扰动小得多。

默认全域／陆地／海洋年均温均保持到两位小数为 **15.18／11.74／16.65°C**；全域／陆地／海洋年雨量 **968.18／658.59／1100.23 → 968.39／659.29／1100.23 mm**。BW 约 **9.76%→9.82%**，BS **22.95%→22.78%**。默认陆地年均径流 **357.93→357.75 mm**，河段数 **1,095→1,094**；Af 仍约 **5.42%**。E0 由默认气候诊断生成，I0/H0/E0 由下游诊断生成；L1、完整自然快照与浏览器链路本轮未运行。

v18 的 Csa 仍不等于用户提供的地球约 2% 陆地参考；海陆与岸线不同，不能按面积硬配额。Csb 已不再明显偏少，但 Cfb 上升，后续仍需用同尺度的沿岸月温观测检查实际幅度。新机制是海洋性年温差近似，不代表冷水上涌或海陆热通量的显式求解。

Stage 版本从 `climate-c0-v17` 升至 `climate-c0-v18`，旧 C0 缓存及下游依赖签名失效；字段、单位、分类规则和公开 API 不变。已新增副热带西岸与极地季节振幅的定向回归用例。按仓库要求，本次未运行 test、build、lint、typecheck 或浏览器检查；新增用例尚未验证。
