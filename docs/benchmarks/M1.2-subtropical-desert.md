# C0 副热带沙漠面积对照

`climate-c0-v13` 按离最近海岸的距离削弱暖干空气混合损失，因此靠近任意海岸的陆地即使位于上风陆地之后，输送水汽也衰减得很少。`climate-c0-v14` 沿陆地到陆地的输送边累积这项损失。直接上岸的海洋水汽仍应用原有基础损失，暖干陆地继续使用既有纬度带、温度、蒸发潜力、风速和衰减尺度。Köppen 判定使用原有月温、月雨规则。

## 固定 Seed

同一 `terrain-v25`，扰动 0.75、倾角 23.5°、降水倍率 1.8。类别占比按输出网格的实际陆地面积加权。连片沙漠由相邻 BW 网格组成，热沙漠 BWh 与冷沙漠 BWk 可归入同一片。

逐区域复算显示，四个样本新增 BW 面积的 **99.9%–100%** 原为半干旱草原 BS。默认样本南北纬 15°–35°、海拔低于 1 km、距海至少 900 km 的低地，年雨量中位数 **342 → 274 mm**，该组 BW 面积占比 **23.7% → 65.6%**。这组低地占默认世界陆地的 **0.68%**。

默认全域／陆地／海洋年雨量为 **985.3／716.0／1100.2 → 977.2／688.8／1100.2 mm**，全球年均温约 **15.19°C**，Af 热带雨林占陆地 **5.83% → 5.53%**。默认 I0/H0/L1 和 E0 生成完成，陆地年均径流 **391.1 → 370.5 mm**，河段数 **1109 → 1107**。地球实测面积比例用于背景参照，各 Seed 的大陆形状与水汽输送共同决定沙漠面积。 [v13 基线](M1.2-west-coast-inland-rainfall.md)
