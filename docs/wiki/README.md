# 另一个地球生成器：地球要素生成原理与方法 Wiki

欢迎阅读 **另一个地球生成器 (Another Earth Generator)** 的底层原理与要素生成技术 Wiki。

当前项目已实现球面地貌生成、第一版年均及月度气候，以及第一版基础地表水文，包括 Fibonacci 球面布点、固定参考网格、板块划分、欧拉运动、边界分类、板块图大陆、构造高程、热点、岛弧、侵蚀与地貌后处理，以及年均风场、海盆、洋流、海温、气温、降水和径流，并由年均场派生 12 个月的第一版季节气温、降水、潜在蒸散和径流。水文阶段进一步生成无洼地排水面、年均汇流和简化河网，并在 3D 地球与 2D 投影地图中显示。生成阶段由 Worker 顺序执行，主线程使用同一份结果显示两种视图。完整水汽平流、正式湖泊、季节性河流，以及第 10～11 章仍在后续实现中。

## 当前实现范围

```mermaid
flowchart LR
    A[参考网格与输出网格] --> B[板块与候选海陆]
    B --> C[构造高程]
    C --> D[地貌后处理]
    D --> E[最终高程与海陆]
    E --> F[3D 地球与 2D 地图]
```

实现顺序与阶段契约见[第 1 章](./01-system-architecture.md)。当前已接入年均大洋与气候阶段，并从年均场派生 12 个月季节气候；基础排水面、年均汇流和第一版河网已接入，湖泊与季节性河流仍处于后续实现阶段。地貌后处理中的汇流图层仍是侵蚀诊断，不等同于水文阶段生成的年均径流河网。每阶段使用确定性输入，并保留必要的中间场以便调试和跨分辨率比较。
