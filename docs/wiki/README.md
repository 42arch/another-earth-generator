# Another Earth Generator Wiki

[English](./README.md) | [简体中文](./README.zh-CN.md)

The Wiki is organized by domain. Nature documents the physical world. Society includes the implemented population, settlement, transport, market, ethnicity, language, polity, and religion stages, plus later design proposals.

- [Nature](nature/README.md): system architecture, spherical mesh, geology, landforms, climate, hydrology, biomes, and rendering.
- [Society](society/README.md): implemented population, settlements, transport, market access, ethnicity, languages, polities, administration, and religions, with planned cultures and history.
