# 09 · 生物群系

[English](./09-biomes-and-ecosystems.md) | [简体中文](./09-biomes-and-ecosystems.zh-CN.md)

## 直观理解

同样多的雨，在炎热地区和寒冷地区能支持的植被并不相同。生成器读取全年每个月的温度与降水，再结合海拔、干燥程度及柯本气候区，把每个最终陆地区域归入一种主要景观类型。

## 实际输出

[BiomeStage](../../../src/core/simulation/pipeline/stages/biome-stage.ts) 在月度气候和柯本分类之后运行。输出网格每个区域有一个 `biomeClass`；还保存按月份天数加权的年均温、年降水、干燥指数和生长季月数。海洋编码为 `0`。当前共有 **15 类编码：海洋加 14 类陆地群系**。完整顺序见 [biome-data.ts](../../../src/core/ecology/biome-data.ts)。

| 编码 | 群系 | 主要判据或景观线索 |
| ---: | --- | --- |
| 0 | 海洋 | 最终海陆掩码为水域 |
| 1 | 热带雨林 | 全年炎热，雨量多且最干月仍有雨 |
| 2 | 热带季节林 | 全年炎热，有较明显的干湿季 |
| 3 | 稀树草原 | 热带热量足，水分低于森林门槛 |
| 4 | 热沙漠 | 干旱且年均温较高 |
| 5 | 冷沙漠 | 干旱且年均温较低 |
| 6 | 半干旱草原 | 低干燥指数或柯本半干旱类 |
| 7 | 地中海灌丛 | 温和区的夏干降水结构 |
| 8 | 温带草原 | 年雨量或生长季不足以稳定成林 |
| 9 | 温带季节林 | 温和、雨量足够的森林区 |
| 10 | 温带雨林 | 温和且雨量特别充沛 |
| 11 | 针叶林 | 寒冷季节明显、暖季能生长 |
| 12 | 苔原 | 最暖月仍冷或生长季过短 |
| 13 | 冰原 | 最暖月低于 0°C，或满足高纬积雪保持近似条件 |
| 14 | 高山苔原 | 高海拔且最暖月偏冷 |

## 分类次序

[分类器](../../../src/core/ecology/biome-classifier.ts) 先处理终年冰冻与高寒山地，再参考柯本 **B** 类识别干旱地，之后用干燥指数、暖月长度、最冷月温度及降水季节性区分森林、草原和苔原。一个地区同时满足多个直观描述时，**代码中的优先级**决定最终类别；表格只是阅读线索。

干燥指数为 `年降水 / 估算年潜在蒸散`。潜在蒸散逐月由温度近似计算，因此它描述“降水相对于热量驱动的水分需求有多少”，并不等于实测土壤湿度。生长季月数统计月均温高于 5°C 的月份。高山苔原还要求海拔至少 2.8 km 且最暖月低于 15°C。

分类器使用与水文相同形式的逐月蒸散需求估算，但两者输出用途不同：水文把每月降水减去需求，生态用**全年降水与全年需求的比值**判断干燥度。热带类别还看最冷月是否至少 18°C，以及最干月降水；温带类别同时看冷季、暖季和降水总量。柯本干旱类别优先参与沙漠/草原判定，避免同一组月气候在两套规则中给出互相矛盾的湿润森林标签。

## 如何读图

“生物群系”图层显示主要类别；区域检查器可显示名称、干燥指数和生长季月数。分类结果不会模拟物种、植被演替、火灾或土地利用。卫星影像层会结合生态、气候和地形做程序化着色，但其颜色不代表遥感观测。
