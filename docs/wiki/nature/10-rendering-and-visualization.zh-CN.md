# 10 · 渲染与交互

[English](./10-rendering-and-visualization.md) | [简体中文](./10-rendering-and-visualization.zh-CN.md)

## 直观理解

你在 3D 地球和 2D 地图中看到的是**同一个世界**。改变视图、图层或月份只是从已有数组挑选数值并重新着色；板块、海陆和河流不会因地图投影而重新生成。

## 两种视图

[WorldEngine](../../../src/core/world/world-engine.ts) 持有生成结果并协调显示。[RendererCore](../../../src/core/world/renderer-core.ts) 管理地球和地图视图。[WorldColorizer](../../../src/core/rendering/shared/world-colorizer.ts) 把每个球面区域的字段映射到颜色，两种视图复用同一语义。

3D 地球把 Voronoi 区域组成球面三角网，支持高程视觉位移、光照、云、大气、经纬线和河流叠加。2D 地图把相同区域投到平面，提供墨卡托与等地球投影；几何在接缝和投影边界裁切。可循环的投影可显示左右相邻副本。相关代码见 [地球渲染器](../../../src/core/rendering/globe/renderer.ts)、[地图视图](../../../src/core/rendering/map/view.ts) 和 [投影定义](../../../src/core/projections/d3-map-projection.ts)。

3D 高程位移是一种视觉夸张，不改变 `geography.elevation` 的物理 km 值。2D 图没有 3D 高度位移。

### 几何与投影细节

地球地表把每个 Voronoi 多边形从中心向角点拆成三角形；顶点携带颜色与法线，三角形对应区域编号供拾取。地图使用同一批球面多边形，但先围绕当前中央经线展开经度，再对投影接缝和纬度范围裁切。墨卡托可水平循环；等地球投影保留完整球形外框，投影逆变换时还会拒绝外框以外的点击。

地球的 [surface-geometry.ts](../../../src/core/rendering/globe/surface-geometry.ts) 与地图的 [surface-geometry.ts](../../../src/core/rendering/map/surface-geometry.ts) 分开构建几何；区域颜色仍来自同一套着色逻辑。这样投影几何能改变，而板块、高程和分类数据不用改变。

大陆、板块、生物群系与 Köppen 气候分类边界由 [SphericalRegionTopologyBuilder](../../../src/core/rendering/shared/spherical-region-topology.ts) 从 Voronoi 共享边构建：同标签内部边被合并掉，跨标签边只生成一次，并按角点连接成闭合环。一个标签可以包含多个环，以表达分离岛屿与孔洞。开启任一图层的区域边界后，边界角点会做两轮轻度球面平滑；多区域交汇点保持固定，地球填色、地图填色和描边共用平滑后的坐标。大陆按最终可见大陆编号区分，板块按 `regionSuperPlate` 区分，生态和气候层按各自的分类编号区分。填色继续由各 cell 的三角网承载；相邻 cell 标签相同、颜色相同，因此这些三角形合起来就是该区划的球面面域，也为大区域提供稳定的内部细分。

## 界面当前开放的图层

图层栏以 [LayerBar.svelte](../../../src/ui/hud/LayerBar.svelte) 为准，当前可选：

| 图层 | 读取的数据 |
| --- | --- |
| 卫星影像、地形图、高程图 | 最终海陆、高程、气候和生态着色 |
| 板块构造 | 细板块编号 |
| 几何汇流 | 地貌阶段的上游单元汇流诊断 |
| 月均气温、月降水量 | 当前月份输出气候场 |
| 盛行风、洋流 | 当前月份的相对向量场；洋流箭头颜色还表示冷暖代理量 |
| 气候分类、生物群系 | 最终输出区域的柯本和生态类别 |

“几何汇流”用于看地形流域形状，不是年流量 m³/s。某些构造与地貌诊断模式仍保留在着色代码里，但图层栏已注释，普通界面无法直接选择。河流和云是单独的显示开关；河流读取最终年均水文结果。

## 拾取与区域检查

3D 视图从鼠标位置射线拾取地表三角形；2D 视图先做逆投影，再定位球面区域。区域检查器展示经纬度、高程、板块、12 个月温雨、年摘要、柯本类别和生物群系等已有字段。月份选择器影响月度温雨与向量图层，不会重算整个星球。具体交互见 [RegionInspector.svelte](../../../src/ui/hud/RegionInspector.svelte)。

切换月份时，主线程从生成结果中取对应月份并更新色彩或向量覆盖层；切换地球/地图时，两视图各自构建显示几何，但共享世界状态。河流条带、云和经纬线可叠在不同底色上。由于河网只在年尺度生成，月度降水图上的河流仍是同一张年均河网。

显示色带与箭头大小只是编码方式。要比较数值，优先看区域检查器和字段单位，尤其不要把相对洋流强度当作 m/s、把冷暖指标当作 °C。
