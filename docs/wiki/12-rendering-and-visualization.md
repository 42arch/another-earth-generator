# 第 12 章 · 球面与地图的共享可视化

> **实现状态：**当前支持 3D 地球、2D 投影地图、地质、地貌、年均与第一版季节气候专题着色、第一版年均河网条带、网格与经纬线、区域拾取。湖泊、道路、航线和地名几何仍待相应生成数据接入。

## 1. 一份球面数据，两种视图

世界生成在 Worker 内完成。主线程收到网格与地质、地理、海洋和气候连续数组后，分别构建 3D 球面视图和 2D 地图视图。两种视图共用区域颜色映射，保持同一专题模式的含义一致；切换视图或外观时无需重算世界数据。

```text
球面网格 + 最终高程 + 地质／地貌／年均与季节气候场
                    ↓
             区域专题颜色
              ↙           ↘
       3D 球面几何       2D 投影几何
```

3D 视图具有地表、可选海面高光球、可选大气、星空、Cell 边界、经纬线、可独立开关并叠加到当前着色模式上的河流条带和选中区域标记。2D 视图具有地表、可选 Cell 边界、经纬线和相同的河流叠加层；使用正交相机，支持平移和缩放。目前没有独立的湖岸、等高线、道路或文字标签图层。

## 2. 3D 地表几何与高程位移

每个 Voronoi 区域由中心和有序角点构成，以中心为扇心划分三角形。几何顶点携带位置、法线和颜色，每个三角形还保存所属区域编号，供拾取使用。地形模式与陆地高度图模式在启用高度位移时，将物理高程反解为仅供显示的形态坐标，再按行星半径的固定比例做径向位移；海底位移幅度较小。其他专题模式使用未位移的球面，便于比较板块与诊断场。

区域中心取本区域高程，Voronoi 角点取相邻区域高程的平均值，以减少高程接缝。陆地高度图也对角点颜色做相邻区域平均。球面地表使用顶点色 Lambert 材质、环境光和方向光；海面高光仅在默认地形模式且启用高度位移时出现。当前没有 Stencil 海陆掩码：地表覆盖完整球面，海面是附加的半透明球层。

## 3. 2D 投影与接缝处理

地图从同一批球面 Voronoi 区域生成平面三角形，可切换**墨卡托**与**等地球**投影。投影前按中央经线展开经度，在经线接缝和投影纬度范围裁切几何；可水平循环的投影会绘制相邻世界副本，使横向拖动连续。Cell 边界与经纬线从球面线段投影，沿用地表的端点处理，以避免边界与填色不重合。2D 模式采用顶点色基础材质，不施加 3D 地形高度位移。

## 4. 已有专题模式

| 类别 | 显示模式 | 数据含义 |
| --- | --- | --- |
| 基础地貌 | 地形、陆地高度图 | 最终物理高程与海陆 |
| 地质构造 | 板块、地壳类型、地壳密度、俯冲极性、构造应力、地幔、火山构造 | 两层板块分析与地质贡献 |
| 地貌诊断 | 地形分类、纹理、最终整形、年均汇流、几何汇流、冰川、水力侵蚀、泥沙沉积 | 最终径流流量、流域单元计数及独立累计侵蚀／沉积厚度 |
| 年均与季节气候 | 盛行风场、气温季节场（陆地气温与海表温度）、海温距平、降水季节场、径流季节场 | 年均场与 12 个月地表气候连续数组 |
| 年均雨影诊断 | 雨影与风向箭头 | 相对关闭地形影响时的降水损失，灰白 0% 至棕红 100% |
| 年均河网叠加层 | 无洼地排水面、年均径流、河流掩码与河级 | 可叠加到任意着色模式的球面河流条带与贴岸河口 |

陆地高度图把海平面及以下显示为黑色，盛行风场图层使用金色箭头显示全年平均风向，箭头长度表示风速。气温专题图层在陆地显示气温、在海洋显示海表温度，并使用同一套温度色带；可选择年均或具体月份。海温距平图层在海洋区域叠加稀疏的洋流方向箭头。降水专题图层在陆地使用年均或当前月份的降水色带，在海洋使用深蓝背景；径流专题图层同步切换年均或当前月份。气温、降水和径流图层共用气候时间选择器，区域检查面板在月度模式下同时显示当前月份值与年均值。

“年均汇流（径流加权）”读取最终正式水文的 `discharge`，单位 m³/s，与河网同源；“几何汇流（单元计数）”沿同一排水图累加上游单元数量。两者使用对数色带，可对比气候权重与流域形状。水力侵蚀与泥沙沉积读取独立累计厚度，按抽样第 98 百分位显色；它们来自初始气候驱动的形态演化，不会随月份选择器变化。

可独立开关河网叠加层，在任意着色模式上以统一蓝色、按汇流量变宽的条带显示年均径流达到阈值的河流单元，源头沿首段渐细渐粗。河道曲线使用更密的球面采样和缓动宽度以减少尖锐拐点。3D 地形启用高程位移时，河道贴合地表并稍微抬高以避免被遮挡，入海段收口到共享海岸边界。纹理、整形及侵蚀等图层也用于定位地貌算法的局部异常，不代表独立的自然要素图层。

## 5. 交互与区域检查

降水图层与 HUD 图例共用 `precipitation-scale.ts`。年降水标尺为 0、5、20、50、100、250、500、1000、2000、3000、5000 mm；月标尺为 0、0.5、2、5、10、25、50、100、200、300、500 mm。各段内部按对数插值，低于 20 mm 的干旱差异和 3000–5000 mm 的湿润差异均可分辨。海洋使用固定深蓝底色，海洋降水数值仍可通过区域检查读取。专题色带只影响显示，不裁剪模拟降水数据。

选择“雨影（年均）”可同时观察降水损失和盛行风方向；该层不随月份选择器变化，河网仍可独立叠加。点击陆地区域，检查面板额外显示雨影百分比、无地形影响参考降水、实际年降水及水汽求解的收敛状态和水量误差。雨影参考降水小于等于 5 mm/年的区域不计算百分比，详见第 7 章。

3D 视图通过光线投射求地表三角形交点，再根据三角形关联的区域编号定位选中区域。2D 视图先把屏幕坐标逆投影为经纬度，再在球面区域中心中寻找方向最接近的区域。两种视图都显示选择标记；检查面板展示区域编号、经纬度、高程、细板块编号、当前时间下的气温和降水，以及对应的年均基准值。

在年均汇流、几何汇流、水力侵蚀或泥沙沉积模式下，检查面板额外展示最终年均径流与流量、累计侵蚀／沉积米数、初始侵蚀驱动径流、局部泥沙滞留及入海输出、全局泥沙收支误差和滞留总量。入海输出目前只做体积记录，并未生成海底三角洲；局部滞留是尚未沉积或输送完的泥沙库存。生态及人文属性仍待接入。
