# 1. 产品愿景与定位

## 1.1 一句话概念

**从一颗星球的自然形成，到智慧生命诞生、文明兴衰与历史更迭；玩家既可以作为旁观者研究世界，也可以作为造物者改写它。**

Another Earth 不是只生成地形纹理的星球展示器，不是只能绘制国界的地图编辑器，也不是只控制国家胜负的战略游戏。它是围绕**一个持续存在的世界**构建的综合模拟和世界创作产品。

## 1.2 产品使命

让用户创造出一个有地理逻辑、社会关系和历史记忆的世界，并能回答：

- 为什么这里形成大陆、山脉、河流和宜居区？
- 为什么城市建立在这里，而不是隔壁山谷？
- 为什么这些民族拥有相近语言，却信仰不同宗教？
- 为什么一个帝国跨越大陆，另一个国家只能守住山口？
- 如果海平面上升、贸易中断、技术突破或领袖更替，世界会如何改变？
- 在一千年以后，谁还记得今天的王朝和边界？

## 1.3 四大产品支柱

| 支柱 | 核心价值 | 用户得到的体验 |
|---|---|---|
| **生成 Generate** | 构建相互约束的自然与人文初始状态 | 每颗星球独特，但地理与文明分布有解释 |
| **演化 Simulate** | 环境、人口、经济、文化和政治自主变化 | 不操作时世界也会产生可理解的历史 |
| **创造 Create** | 编辑自然、文明、制度、事件与历史分支 | 可自由创作，而不因一次修改失去其余成果 |
| **探索 Explore** | 地图、时间轴、百科与统计联动 | 能发现、理解并讲述世界自己的故事 |

## 1.4 差异化定位

1. **自然与文明是同一个世界，而不是两份独立的随机结果。** 环境限制生产，生产影响人口，人口推动城市与国家，国家反过来改变土地利用和环境。
2. **支持观察者体验。** 用户不必扮演某个国家、完成任务或维持高操作频率；看世界自己运转本身就是核心玩法。
3. **支持创作者体验。** 用户可创作世界地图、定制文化、书写历史，并在编辑后继续模拟。
4. **强调因果可解释。** 对关键变化给出因素与事件链，不以“随机发生”替代社会机制。
5. **二维地图与三维星球平等重要。** 3D 表现全球形态与空间环境，2D 便于编辑、对比与历史研究。
6. **世界具有连续身份。** 山脉、城市、国家和民族都有名称、起源、演变与可能的终结，而不是每个时间点完全重抽一次。

## 1.5 核心用户

| 用户 | 主要诉求 | 关键能力 |
|---|---|---|
| 世界观创作者 | 为小说、TRPG、游戏构造可信世界 | 生成、地图编辑、命名、百科、历史导出 |
| 模拟与策略爱好者 | 观察文明兴衰、经济联系、政治变化 | 自主演化、事件、战争、外交与历史回放 |
| 地理与自然爱好者 | 理解地形、气候、河流和生态分布 | 自然专题图、参数实验、因果说明 |
| 地图制作者 | 制作具有特定风格的星球和政治地图 | 2D/3D 视图、样式、图层、制图与导出 |
| 沙盒实验用户 | 进行“如果……会怎样”的实验 | 世界规则、情景干预、历史分支、对比 |

## 1.6 不以这些内容作为核心目标

- 不以真实地球天气预报或专业科研数值精度为产品承诺。
- 不以微观人物生活或城市逐栋建筑模拟代替全球尺度的文明模拟。
- 不以实时战斗操作、动作游戏或国家征服胜负作为唯一玩法。
- 不以自动生成大段故事文字代替可追溯的世界事实。
- 不追求同时精细模拟全部物理、生态、社会细节；根据尺度选择合理抽象。

# 2. 核心设计原则与世界规则

## 2.1 因果优先于随机

随机性决定差异，规则决定合理性。一个事件至少应有**触发条件、影响对象、主要原因、结果与可追踪后果**。例如饥荒可以由持续干旱、歉收、贸易封锁与治理失败共同造成，而不是每十年直接随机扣除人口。

## 2.2 多尺度一致性

世界同时存在四种观察尺度：

| 尺度 | 重点对象 | 典型观察 |
|---|---|---|
| 行星 | 轨道、海陆、气候带、洋流 | 全球宜居性、冰期、海平面 |
| 大洲／区域 | 流域、生态区、文化圈、贸易网络 | 人口迁移、土地利用、文明传播 |
| 国家／城市 | 行政、人口、经济、制度与外交 | 城市兴衰、国家治理、资源竞争 |
| 地点／事件 | 港口、遗迹、圣地、战役、灾害 | 具体故事及其在世界历史中的位置 |

在不同尺度下切换细节，不应产生互相矛盾的事实。城镇人口已包含在区域总人口内，国家人口来自其实际控制或归属人口，绝不重复加总。

## 2.3 约束与守恒

- **面积约束：** 陆地、海洋、领土、生态区的地理范围明确，重叠与交集有相应语义。
- **人口约束：** 出生、死亡、迁入、迁出和重新归类共同解释人口变化；族群与宗教分类不能凭空创造居民。
- **资源约束：** 生产受土地、资源、技术、劳动与运输限制；消费和积累具有来源。
- **交通约束：** 山脉、海峡、距离、季节、基础设施和政治限制影响通达性。
- **生态约束：** 气温、降水、水、土壤和人为活动共同影响生态与粮食容量。
- **时间约束：** 一座城市、一个国家或一种信仰的形成、传播和消亡需要过程，不应瞬间覆盖整个星球。

复杂模型允许近似，但界面应说明“模拟值”“估算值”“分类值”和“人为设定值”的区别。

## 2.4 没有单一的文明胜利路线

社会发展的目标、价值和组织形态应是多样的。技术先进不必然意味着政治统一，人口众多不必然意味着军事强大，文化差异不应固定映射为文明高低、道德优劣或天生敌意。

物种特征主要影响生理适应与需求；文化、制度和历史结果应可学习、传播、分化与改变。

## 2.5 让用户控制“干预程度”

提供三个干预等级：

- **观察：** 只调整速度、地图和关注对象，不改变世界事实。
- **引导：** 提供环境、政策倾向或情景条件，允许世界自主响应。
- **创世：** 直接修改地形、城市、国家、文化和事件，但标记人为干预及其影响。

用户始终可选择“不干预”。

## 2.6 连续世界与可回溯历史

历史不只是地图随年份变色。一个对象必须有完整的生命周期概念：建立、成长、分裂、合并、迁移、改名、灭亡、被继承或留下遗迹。

任何人工干预都应可以查看前后差异，并在需要时从历史时点创建一个新的世界分支。

# 3. 产品模式、用户旅程与交互循环

## 3.1 五种模式

| 模式 | 用户目的 | 主要交互 | 是否改变世界 |
|---|---|---|---|
| **创世 Genesis** | 设定条件并生成初始世界 | 模板、种子、参数、预览、生成 | 创建新世界 |
| **观察 Observe** | 探索当前世界和实体 | 地图、搜索、选中、分析、收藏 | 否 |
| **演化 Evolve** | 推进世界时间 | 播放、暂停、速度、事件关注、干预 | 是 |
| **编辑 Create** | 修改地理、人文与叙事 | 画笔、属性编辑、批量操作、锁定 | 是 |
| **历史 Chronicle** | 回看、比较、分支与讲述历史 | 时间轴、对比、事件档案、书签 | 默认否；分支后可演化 |

五种模式共享同一世界；不应要求用户分别进入五个彼此隔离的项目。

## 3.2 三个核心用户循环

**创作循环：** 创建世界 → 浏览地图 → 定位不满意处 → 编辑地形或人文 → 预览连锁影响 → 确认 → 保存为新的版本。

**观察循环：** 选定关注对象 → 运行时间 → 收到重要事件 → 查看原因 → 切换专题图 → 比较此前状态 → 收藏这段历史。

**实验循环：** 保存关键时点 → 设置单一变量或施加干预 → 推进同一时间跨度 → 与基准世界对比 → 解释差异。

## 3.3 新用户首次体验

1. 进入产品，选择**随机类地球**、**预设星球**或**从参数创建**。
2. 生成后首先看到完整星球，可切换地形、气候、生态、政治四种快速视图。
3. 首次引导展示三个“为什么”：为什么此处多雨、为什么此处有城市、为什么此处形成国家。
4. 单击播放，观察几十年变化；出现一条完整的重大事件，例如城市建立、王朝更迭或边界冲突。
5. 选择一个城市，打开其历史和变化曲线。
6. 在地图上创建一条道路或更改气候条件，观察世界后续不同发展。
7. 保存世界、制作一张历史地图或导出观察结果。

## 3.4 核心界面信息架构

| 区域 | 内容 | 交互原则 |
|---|---|---|
| 主视口 | 3D 星球或 2D 地图 | 最大化可视区域，可自由平移、缩放、旋转与选择 |
| 左侧导航 | 图层、世界要素目录、搜索、编辑工具 | 同类工具归类，支持收起 |
| 右侧详情 | 当前选中的地区、城市、国家、物种或事件 | 事实、变化、原因、关系、历史链接 |
| 顶部 | 世界名称、模式、视图、存储状态、全局操作 | 常用动作稳定且少 |
| 底部时间轴 | 年代、播放、速度、书签、重要事件 | 能随时暂停、回溯和比较 |
| 浮动分析面板 | 图例、统计图、对比、剖面、测量 | 只有按需打开时才占用主视口 |

## 3.5 用户旅程验收

- 用户不阅读手册也能在首次使用中生成星球、切换两种地图并选中城市。
- 从地图上的任意文明要素可到达其百科资料和历史。
- 从任意重大事件可定位发生地点、相关实体和时间。
- 用户能够理解哪些操作会修改世界、哪些只是改变显示。
- 世界运行中发生重大事件时，用户可以不中断模拟也可以选择暂停查看。

# 4. 世界配置与创世流程

## 4.1 创世向导

推荐依次配置：**世界原型 → 天文与行星 → 地质与海陆 → 气候与生态 → 智慧生命 → 文明起点 → 模拟规则 → 生成预览**。

默认提供**简易**与**高级**两套设置，简易模式只暴露少量高影响参数，高级模式允许控制更多相关条件。所有参数需要说明它可能影响哪些世界特征。

## 4.2 世界原型

| 原型 | 视觉特征 | 模拟重点 |
|---|---|---|
| 标准类地球 | 多大陆、温带与热带、广泛海洋 | 全面自然与文明 |
| 超级大陆 | 单一巨大大陆与广阔海洋 | 内陆干旱、跨大陆陆路竞争 |
| 群岛世界 | 海岛众多、海峡复杂 | 航运、港口、海洋文化、岛屿生态 |
| 海洋行星 | 海洋占优、陆地稀少 | 沿海聚落、渔业、岛链贸易 |
| 干旱世界 | 稀少地表水、荒漠广布 | 绿洲、灌溉、资源与水权 |
| 冰封世界 | 冰盖广阔、短生长季 | 生存适应、冰期变化 |
| 温室世界 | 高温、强降水与极端天气 | 生态生产力与气候风险 |
| 火山活跃世界 | 板块运动和火山岛突出 | 构造灾害与矿产 |
| 奇幻世界 | 可配置异常生态与文明规则 | 世界观创作，但保留可解释约束 |
| 空白沙盒 | 用户自定义主要地貌和文明 | 精细创作 |

模板是参数组合和初始约束，不是完全写死的地图。

## 4.3 天体与物理条件

| 类别 | 主要可配置项 | 用户可见影响 |
|---|---|---|
| 恒星 | 辐照强度、光谱类型（高级） | 全球能量、可生存温度区间 |
| 轨道 | 公转周期、离心率 | 季节时长、季节强弱 |
| 自转 | 日长、自转方向 | 昼夜变化、环流倾向 |
| 轴倾 | 倾角、季节相位 | 纬度间的季节差异 |
| 行星 | 物理半径、表面重力、平均密度 | 物种适应、地形与大气约束 |
| 大气 | 厚度、温室强度、主要成分概念 | 温度、宜居性、天气潜力 |
| 水量 | 海洋总量、目标海陆比 | 海平面、海洋范围与陆地形态 |
| 卫星 | 月亮数量、潮汐强度 | 潮汐、海岸环境、历法文化 |
| 地质活动 | 板块活跃度、火山频率 | 山系、岛弧、地震与矿产 |

**基础体验默认为可居住类地球。** 极端星体参数若使智慧生命无法自然生存，应明确提示用户，允许选择“无文明世界”“外来殖民者”或启用相应的非现实世界规则。

## 4.4 自然参数

| 模块 | 主要配置 | 设计影响 |
|---|---|---|
| 大陆 | 数量、大小差异、破碎程度、海陆比 | 陆地版图与海峡数量 |
| 板块 | 大板块、小板块、活动度 | 构造边界与山脉分布 |
| 地形 | 起伏、侵蚀、山脊、海岸曲折 | 高程与可通行性 |
| 水文 | 蒸发/径流强度、湖泊倾向、湿地覆盖 | 河湖水网与淡水可用性 |
| 气候 | 轴倾、基准气温、降水强度、季风倾向 | 气候带、季节性 |
| 生态 | 生产力、生物多样性、生态恢复力 | 生物群系、资源与环境韧性 |
| 灾害 | 地震、火山、洪水、干旱、风暴频度 | 风险空间分布与后续事件 |

## 4.5 人文初始参数

| 模块 | 主要配置 | 设计影响 |
|---|---|---|
| 智慧物种 | 物种数、生理差异、初始分布 | 宜居区与人口生态位 |
| 人口 | 总量倾向、聚落密度、迁徙能力 | 人口空间分布 |
| 社会起点 | 狩猎采集／农耕／古典／中古／工业／现代 | 初始社会复杂度与技术条件 |
| 文化 | 初始文化圈数、差异强度、融合倾向 | 文化与语言多样性 |
| 宗教 | 信仰类型多样性、传播倾向 | 信仰分布与宗教机构 |
| 政治 | 初始政体数、治理能力、分裂倾向 | 国家规模、组织方式与边界 |
| 经济 | 资源丰富度、专业化、贸易开放度 | 产业与贸易网络 |
| 历史 | 初始文明年龄、历史事件密度 | 起始世界是否已有遗迹、旧王朝和历史关系 |

## 4.6 起始年代方案

- **原始自然：** 无智慧文明，重点观察地质、气候与生态。
- **智慧生命起点：** 有物种和部落，尚无成熟国家。
- **农业文明起点：** 有农田、河谷聚落、语言和初级制度。
- **古典世界：** 有城邦、王国、商路和复杂信仰。
- **中古／早期帝国：** 有国家体系、宗教组织、技术传播和跨区域贸易。
- **工业／现代：** 复杂产业、人口结构、制度和环境影响。
- **自定义历史起点：** 手工设定某个时代、主要国家和冲突，作为新的演化起点。

## 4.7 生成结果与质量提示

生成完成时提供创世摘要：陆地比例、大洲数量、极端高程、主要流域、气候分布、生态区、宜居区、人口总量、主要城市、国家、文化与宗教数量。若出现极端条件，例如无适合农业的陆地，应呈现为有意义的世界特征，而不是隐藏或强行修正。

**验收：** 同一世界配置和生成规则下，用户可重复得到一致的初始世界；改变显示样式不会改变自然或文明事实；所有可配置项具有合法范围及异常条件反馈。

# 5. 自然世界：行星、地质、地形、气候、水文与生态

> 产品要求：自然系统不仅为地图提供颜色，还要共同决定世界的宜居性、生产力、通行成本、自然风险与长期变化。

## 5.1 行星环境与天体影响（NAT-01）

**目标：** 用户能够理解一颗星球为什么会有当前的昼夜、季节、温度范围和大尺度环境。

**核心内容：**

- 太阳辐照与温室效应共同决定基准热环境。
- 轴倾与公转周期决定季节长度、极昼极夜与不同纬度的日照差异。
- 自转影响大气及海洋环流的宏观方向。
- 地表重力、海洋规模和大气状态影响地形与宜居性边界。
- 卫星与潮汐影响海岸带生态及部分文明生产活动。
- 支持行星环境的稳定状态、周期变化和长期扰动。

**可观察成果：** 太阳入射、昼夜界线、四季日照、全球热量分布、海洋覆盖、宜居区范围。

**产品边界：** 深空天体碰撞和完整多体轨道动力学属于愿景扩展，不作为核心文明模拟的先决条件。

## 5.2 地质、板块与地貌形成（NAT-02）

**主要对象：** 板块、地壳、板块边界、造山带、洋中脊、海沟、火山带、热点、断层、地质区域。

**生成规则：**

1. 初始地壳与板块分布具有空间连续性。
2. 汇聚、张裂和走滑边界对应不同地貌倾向。
3. 大陆与岛弧的形成受到构造、海平面与火山活动的共同作用。
4. 构造贡献形成大尺度高程，局部侵蚀与沉积进一步塑形。
5. 地貌、断层与火山分布影响自然灾害、矿产与交通。

**长期演化：** 山脉抬升、海盆变化、火山造岛、侵蚀和沉积。以地质年代为独立观察时间尺度；不要求每个文明年都重塑板块拓扑。

**展示内容：** 主要板块、运动方向、边界类型、构造应力、地壳类型、年龄、火山风险和地形剖面。

**验收：** 主要山脉和火山带分布与相应地质条件存在可解释关联；改变构造条件后能观察到具因果关系的地貌差异。

## 5.3 地形、海岸与陆地形态（NAT-03）

**地形类别：** 海沟、深海盆、陆架、海岸平原、丘陵、山地、高原、盆地、峡谷、河谷、沙丘、冰川谷、火山台地。

**核心规则：**

- 大陆总面积和数量是生成目标，不应直接把目标数字等同于最终可见大陆数量。
- 海岸线受地形、海平面、沉积和波浪作用影响。
- 侵蚀有来源和方向：雨水与河流塑造谷地，冰川影响高纬高山，风影响干旱地区。
- 高程连续，不能无解释地出现大范围单格噪声山峰。
- 地形具备可用于文明选择的坡度、可通行性、洪水风险和耕作适宜性。
- 存在内陆盆地、封闭流域、岛屿与峡湾等特殊环境。

**动态变化：** 海平面升降、海岸线迁移、三角洲增长、沙漠化和土壤退化；这些变化会影响已有城市、道路与耕地。

**可编辑性：** 提升、降低、平整、绘制山脉、调整海岸、挖掘盆地、保护指定地貌、指定地形类型。

## 5.4 气候与大气（NAT-04）

**基础气候量：** 月平均温度、昼夜及季节温差概念、降水量、降水季节性、风向与风强、湿度、潜在蒸发、积雪、海表温度代理、极端天气风险。

**气候驱动：** 纬度、海陆位置、海拔、坡向、大型山系、风场、洋流、季节、温室强度、植被覆盖与长期环境扰动。

**必须表达的现象：**

- 热带辐合与季风性降雨。
- 盛行风、迎风坡降雨和背风雨影。
- 沿海与大陆内部的气温和季节差异。
- 冷暖洋流对沿海气候的修正。
- 冬季积雪、冰雪覆盖与高纬季节变化。
- 干旱、热浪、寒潮、暴雨和风暴的空间风险。

**分类结果：** Köppen 气候区、干湿分区、生长季与农业适宜性；分类应可追溯到实际气候条件。

**时间设计：** 默认提供 12 个月气候观察和年度统计；长期可查看多年气候异常、环境趋势与气候变化事件。

**验收：** 极地与热带总体温度分布合理；山系两侧在适当气候下出现差异；调整轴倾会改变季节性；调整全球温室强度会影响宜居范围而非仅改变地图颜色。

## 5.5 海洋与海岸生态（NAT-05）

**核心内容：**

- 海洋深度与海底地貌、海面和海岸带。
- 洋流方向、寒暖流影响、海表热异常。
- 海冰范围的季节变化。
- 海岸资源、渔场潜力、港口条件、可航行海峡。
- 近海生态环境：珊瑚礁、红树林、滩涂、海草床、深海生境等适宜性分布。
- 大尺度海洋生态生产力与食物资源的空间差异。

**文明联系：** 海岸不仅是陆地边缘，也是食物、运输、贸易、文化传播和军事通道。

## 5.6 水文与淡水系统（NAT-06）

**核心对象：** 分水岭、流域、河流、支流、源头、河口、三角洲、湖泊、内流盆地、湿地、冰川、积雪、地下水和蓄水区。

**核心规则：**

- 降水、融雪、蒸发与地表条件共同决定水量来源。
- 河流具有上游、下游、汇流关系及季节性差异。
- 河流流量随汇水面积、降水和季节变化，不应仅由绘制宽度决定。
- 地形洼地可形成湖泊、湿地或封闭汇点，并具有水量收支。
- 干旱地区可能形成季节河、间歇湖和绿洲。
- 洪水可能扩大耕地肥力，也可能破坏聚落与交通。
- 水资源的可获取性直接影响人口和农业，不等同于距离河道最近。

**地图与信息：** 河道级序、流量分级、流域边界、水量收支、洪水危险区、季节水网、湖泊水位趋势。

**文明联系：** 灌溉、航运、筑坝、城市供水、水权争端与水患治理。

**验收：** 河流不无故从低处流向高处；无水量来源的河流不长期维持大流量；封闭盆地与海洋出海口的规则清晰；编辑水文条件后可检查受影响的农业与聚落。

## 5.7 土壤、生态与生物群系（NAT-07）

**主要环境：** 热带雨林、季雨林、草原、稀树草原、温带森林、针叶林、地中海植被、荒漠、冻原、冰原、湿地、高山带、淡水和近海生态区。

**关键变量：** 气候适宜度、土壤肥力、水分、养分、地表覆盖、生物量、初级生产力、生物多样性、生态恢复能力、人类干扰。

**生态行为：**

- 气候与地形决定潜在生物群系；真实覆盖还受火灾、疾病、农垦和采伐影响。
- 森林扩张、草地演替、沙漠化、湿地退化、土壤恢复和植被破坏需要时间。
- 动物与植物的自然分布具有生境限制和传播途径。
- 生态破碎化可能降低物种多样性并影响农业、渔业与疾病风险。
- 外来物种、岛屿隔离和大灭绝可作为高级生态事件。

**建议区分：** 潜在生物群系（自然条件下适宜）与当前土地覆盖（真实存在），避免将“适合森林”与“实际有森林”混为一谈。

## 5.8 资源与自然生产条件（NAT-08）

**资源体系：**

| 类型 | 代表资源 | 主要影响 |
|---|---|---|
| 淡水 | 河湖、地下水、冰川融水 | 饮水、灌溉、工业 |
| 农业 | 可耕地、牧场、林地、渔场 | 粮食、纤维、畜产品 |
| 建筑 | 石材、黏土、木材、砂石 | 聚落与基础设施 |
| 金属矿产 | 铜、铁、锡、金、盐、稀有金属 | 工艺、武装、贸易 |
| 能源 | 木材、煤、油气、地热、风、水、太阳 | 生产方式与技术跃迁 |
| 战略资源 | 稀缺矿物、肥沃河谷、关键水道 | 外交、贸易、冲突 |

资源同时拥有**分布、储量或可再生能力、开采难度、可获得性、生态代价**等概念。

对农业而言，潜在粮食生产受气候、水、土壤、工具、劳动力及土地使用共同影响。地区“有矿产”与“拥有开采能力”应是两种不同事实。

## 5.9 自然灾害与长期环境事件（NAT-09）

| 灾害 | 发生条件 | 可能后果 |
|---|---|---|
| 地震 | 活跃断层与构造应力 | 建筑损坏、交通中断、次生滑坡 |
| 火山喷发 | 火山活动带和热点 | 火山灰、肥沃新土、人员迁离 |
| 海啸 | 海底强震或海底滑坡 | 港口与海岸损毁 |
| 洪水 | 强降水、融雪、流域水量异常 | 农田损失、沉积、疫病风险 |
| 干旱 | 持续水分赤字 | 饥荒风险、迁徙和水权冲突 |
| 风暴 | 热量、水汽与大气条件 | 航运停滞、海岸破坏 |
| 野火 | 干热、植被燃料与诱因 | 森林损失、生态更新 |
| 寒潮／热浪 | 大气异常和季节条件 | 健康、能源和农业冲击 |
| 冰期／海平面变化 | 长期气候驱动 | 海岸迁移、生态区变化、领土损失 |

自然灾害需要保留**发生地点、开始与结束时间、强度、受损资源、人口与历史影响**。并非所有灾害都必须引起文明崩溃；社会韧性、基础设施和治理可以改变结果。

## 5.10 自然模块产品验收

- 自然数据在地理空间上连续且有合理边界。
- 自然专题图中可查看来源因素，而不是只有一个数值。
- 河网、水量、生态适宜度与地形、气候存在有意义的联动。
- 至少支持季节尺度的自然变化；高级版本支持长期生态与气候趋势。
- 同一地区的环境信息在 3D、2D、统计和百科中保持一致。

# 6. 智慧物种、文明与社会体系

> 产品要求：文明不是在地图上涂色的国家生成器；文明是一组有出生、需求、生产、文化、联系、组织和历史的社会实体。以下模块既用于创世初始状态，也规定长期演化中的行为。

## 6.1 智慧物种与生物适应（SOC-01）

**物种维度：** 外形主题、寿命与世代、成熟年龄、生殖方式、基础营养需求、生存温度、需水量、活动节律、迁徙倾向、疾病敏感性、地理适应、生理多样性。

**物种起源：**

- 原生演化：出现于适宜生态区，有相对连续的扩散历史。
- 多起源：多个物种或亚群在不同环境出现。
- 外来定居：从世界之外进入某个地区，适合情景创作。
- 奇幻物种：使用可明确声明的世界观规则而非默认物理解释。

**物种不是文化。** 同一物种可能分化为多种语言、民族和国家；不同物种也可以共享政治组织、文化和信仰。

**产品原则：** 特征应尽量表达生理需求和环境适应，不将所谓“好战”“聪明”“文明”固定为不可改变的种族本质。群体行为主要由社会环境、制度、资源和历史驱动。

**可观察信息：** 起源地、迁徙路线、分布、人口、平均寿命、环境适应范围和物种关系。

## 6.2 人口与人口学（SOC-02）

**核心概念：** 区域人口、城乡人口、年龄结构、出生、死亡、预期寿命、健康水平、迁入迁出、受教育程度、劳动参与、阶层与职业。

**初始生成：** 人口起源于资源与环境允许的居住区，同时受技术、社会起点、迁徙能力、危险和历史条件约束。

**动态发展：**

- 粮食、住房、水、医疗、安全和公共卫生影响人口变化。
- 年龄结构影响生育、劳动供给和社会负担。
- 人口增长不应长期无限指数扩张；存在资源、技术和社会条件的约束。
- 迁徙方向受就业、土地、贸易、语言网络、战争、环境与政策影响。
- 城市人口集中来自乡村迁入、人口自然增长和经济吸引力。
- 饥荒、战争和疫情改变人口规模，也改变迁徙与长期年龄结构。

**多重身份：** 一名居民可以同时属于物种、民族、语言群体、宗教、职业、社会阶层和国家，但每种分类的统计口径应独立。跨分类展示交叉分布时避免重复计数。

**验收：** 总人口变化能够被出生、死亡和迁移解释；城市人口已计入区域人口；民族与信仰人口构成不会额外增加总人数。

## 6.3 聚落、城市与城市网络（SOC-03）

**聚落层级：** 营地／村庄／集镇／城镇／城市／都会／都市圈。层级由人口、功能和区域影响力决定，不只依赖一个固定阈值。

**选址因素：** 淡水、耕地、天然港口、交通交汇、矿产、避险、战略要道、宗教圣地和行政需求。

**城市属性：** 名称、坐标、建立时间、人口、面积、等级、城市功能、资源、所属行政区、经济部门、基础设施、公共服务、文化构成、环境风险、历史事件。

**城市功能：** 农业中心、商港、矿业城、军镇、学术中心、宗教城市、行政首都、制造业中心、旅游与文化中心等。一个城市可具有多重功能。

**发展机制：**

- 农业剩余、市场可达性和技术支持更大规模的非农业人口。
- 城市之间形成分工、竞争、通勤和贸易网络。
- 交通路线变化、资源枯竭、战争与气候变化可能导致城市衰落。
- 首都迁移或政治变动不一定造成原首都立即消失。
- 被毁灭的城市可能留下遗址、历史名称和再定居机会。

**展示：** 城市等级符号、人口圈层、功能图标、城市关系线、增长曲线、城市档案、历史地图。

## 6.4 土地利用与基础设施（SOC-04）

土地利用类别包括自然林地、耕地、牧场、居民地、矿区、工业区、交通用地、保护区和退化地。

主要基础设施包括道路、桥梁、渡口、港口、运河、铁路（工业以后）、水库、灌溉区、公共卫生与供水设施。

**规则：** 基础设施建造需要资源、劳动力和组织能力；维护需要持续投入。交通设施降低实际出行成本，扩大城市腹地，改变市场与国家治理能力，同时可能破坏生态。

## 6.5 经济、生产与消费（SOC-05）

**目标：** 让国家繁荣、贸易往来、人口增长和危机具有真实的资源约束，而不只是一个抽象经济评分。

**生产部门：** 粮食、畜牧、渔业、林业、采矿、冶炼、手工业、制造业、能源、运输、商业与服务。

**经济核心流程：**

1. 地区拥有自然资源和可用土地。
2. 人口提供劳动，技术和组织决定生产能力。
3. 生产形成粮食、材料、工具、能源和服务。
4. 居民、城市和国家消耗商品与服务，未消费部分可形成储备或资本。
5. 贸易在地区间转移商品，受到运输费用、市场规则和政治障碍限制。
6. 供需失衡、生产受损或运输中断导致价格、库存及生活水平变化。

**经济层级：**

| 层级 | 要回答的问题 |
|---|---|
| 地区 | 生产什么、需要什么、能否自给？ |
| 城市 | 依赖哪些腹地和贸易路线？ |
| 国家 | 税基如何、支出在哪里、贸易依赖多大？ |
| 世界 | 哪些资源形成跨洲交换网络和经济中心？ |

**关键指标：** 粮食平衡、生产能力、消费需求、供给缺口、贸易额、生活水平、价格水平、财富或收入差异、财政收支、就业结构。

**演化规则：** 经济特征应形成区域分工；技术进步可以提高生产率，但有设备、能源、制度和扩散条件；禁止凭空大量生产原料或出现没有运输路径的跨海贸易。

**范围分级：** 基础版以重要商品类别和总体产出为主；高级版支持更细的行业、商品链、市场价格、企业／生产组织和国家预算。

## 6.6 交通、航运与贸易网络（SOC-06）

**网络：** 步道、陆路、商道、河运、海路、港口、运河、铁路、现代运输走廊。

**行为规则：**

- 路线选择权衡距离、坡度、海峡、河谷、风险、基础设施和政治通行权。
- 港口需要自然条件、腹地需求和建设能力。
- 沿路交流促进技术、语言、宗教和疾病传播。
- 交通形成市场可达性，但**通达性不等于实际贸易量**。
- 战争、海盗、疫情、封锁与灾害可中断路线并迫使货流改道。
- 新运河、跨海通道或海上航路发现可能改变全球经济格局。

**展示：** 路线类型、通行成本、商路等级、贸易方向、主要货物、港口腹地、通商瓶颈、区域网络中心性。

## 6.7 民族、文化与语言（SOC-07）

**区分概念：**

- **物种：** 生物学类别。
- **民族／族群：** 历史形成的集体认同，不必与国家或语言一一对应。
- **文化：** 价值、习俗、知识、艺术、家庭与生产实践的集合。
- **语言：** 可传承、扩散、分化和融合的交流体系。
- **语系：** 语言历史关联的抽象谱系，不自动代表现代政治联盟。

**文化特征：** 定居与游牧倾向、亲属结构、贸易习惯、艺术与建筑审美、饮食、法律观念、社会规范、教育与知识传承。

**演变规则：** 迁徙、隔离、通婚、通商、征服、教育、宗教改革和政治制度影响文化与语言传播。允许多语、混合文化、文化边界与政治边界不重合、少数族群长期共存。

**历史结果：** 方言分化、语言形成与消亡、文化融合、民族认同改变、名称变化、散居群体和侨民网络。

**验收：** 某地区的主要语言和民族不必与国家官方语言一致；文化影响能跨国境传播；分类变化有历史背景。

## 6.8 宗教、哲学与信仰（SOC-08）

**信仰类型：** 地方信仰、祖灵崇拜、多神教、一神教、哲学传统、世俗思想体系、混合信仰，以及可配置的奇幻超自然传统。

**信仰结构：** 起源地、创始故事、核心教义、圣地、仪式、传播范围、宗教组织、分支、改革、与政治权力的关系。

**演化规则：**

- 宗教可以随贸易、迁移、传教和征服传播。
- 语言文化接触有利于传播，但并不保证自动同化。
- 政策、教育和地方社会结构影响宗教支持与变化。
- 宗教可能分裂、融合、改革、衰落，也可能复兴。
- 圣地和朝圣路线对城市、贸易和政治具有影响。
- 国家支持的宗教与居民实际信仰分布分开记录。

**表现：** 分布地图、宗教关系树、时间轴、圣地、宗教冲突和共存状态。高级模式支持多重信仰和实践，不强制所有居民只能拥有一组排他性观念。

## 6.9 国家、政体与治理（SOC-09）

**政治实体类型：** 城邦、部落联盟、王国、帝国、共和国、邦联、神权国家、游牧政权、自治共同体、联邦与现代民族国家等。

**核心属性：** 名称、起源、首都、行政中心、有效领土、宣称领土、人口、文化与宗教组成、制度、统治者或领导集团、治理能力、财政、法律、稳定性与合法性。

**国家形成：** 军事组织、城市联盟、贸易共同体、部落整合、宗教权威或外来征服等不同路径，不应只有“首都向外扩张”一种原因。

**领土与治理：**

- 区分实际控制、名义主张、边疆影响与争议领土。
- 山脉、荒漠、海峡、道路和行政能力影响治理成本。
- 国家不必完全覆盖所有陆地，允许无国家地区和混合边境。
- 大国家可能因交通成本、财政、继承冲突和地方差异而分裂。
- 政体可以改革，国家名称和边界可改变，但保留历史身份与继承关系。

**内政：** 税制、公共投资、宗教政策、教育、军政关系、贸易政策、地方自治、社会权利与环境治理。政策效果受资源、制度与实施能力约束。

## 6.10 外交与国际关系（SOC-10）

**关系状态：** 友好、紧张、中立、敌对、从属、保护、联盟、停战、战争等，并有连续变化的信任与利益评估。

**可形成的协议：** 贸易协定、通行权、互不侵犯、共同防御、婚姻／王朝安排（适用时代）、边界条约、保护国关系、宗教协定和资源共享协议。

**冲突来源：** 领土争议、水源、战略通道、资源、迁徙压力、宗教政治矛盾、历史恩怨、扩张主义与安全困境。

外交关系应可能改善，也可能恶化；共享语言与宗教是影响因素，不是机械的必然盟友规则。

## 6.11 军事、战争与和平（SOC-11）

**产品定位：** 战争是文明关系、地理条件与国家组织的结果，不是默认的地图涂色竞赛。

**军事因素：** 人口动员、粮食供给、技术、生产能力、财政、士气、地形、天气、道路、海运、指挥和后勤。

**冲突生命周期：** 边境摩擦 → 政治要求 → 外交或战争 → 战役与占领 → 战损和民生变化 → 和平条约 → 战后治理及长期记忆。

**战争后果：** 人口伤亡、迁徙、经济破坏、基础设施损失、领土变化、国家合法性变化、战争债务、技术传播和文化影响。

**和平机制：** 结盟、调停、停火、割地、赔偿、自治、朝贡或资源条约；避免战争只能以一方被完全消灭结束。

**展示层：** 军队态势、冲突地区、战线、补给通道、战争阶段、历史战役和伤亡统计。基础产品以战略与区域结果为主，不要求即时战场单位操作。

## 6.12 科技、知识与时代发展（SOC-12）

**领域：** 农业、建造、航海、交通、冶金、能源、医学、教育、行政、通信、军事、科学方法、工业与环境治理。

**发展规则：**

- 技术进步受需求、人才、教育、资源、专业化和社会组织影响。
- 技术可通过贸易、移民、学术、战争、模仿和传播扩散。
- 不同文明具有不同技术结构与优势，不采用严格线性、单一路径的“科技等级”。
- 发现不等于普及；技术使用需要劳动力、资源与制度支持。
- 某些技术带来增长，也可能造成新风险、环境代价或政治冲突。

**时代：** 石器与采集、农业兴起、金属工具、古典城市、跨海贸易、印刷与知识传播、工业化、现代全球联系、高级未来文明。时代为观察标签，不是所有地区必须同时进入的统一等级。

## 6.13 社会群体、制度与内部政治（SOC-13）

**社会结构：** 农民、工匠、商人、士兵、学者、官员、宗教人士、贵族／地方精英、工业工人和其他随时代变化的职业及阶层。

**社会指标：** 收入与生活水平、受教育程度、政治参与、地方认同、制度支持、社会流动、公共服务、阶层差异。

**变化来源：** 经济转型、人口压力、技术创新、迁徙、税收、改革、战争和资源危机。

**历史现象：** 政策改革、自治运动、继承争端、叛乱、分离、政变、社会运动和制度更替。它们应有可查明的动因和支持基础。

## 6.14 疾病、公共卫生与生活质量（SOC-14）

**基础因素：** 人口密度、卫生条件、营养、水质、交流网络、医学水平及环境风险。

**可能现象：** 地方性疾病、跨区域流行病、饥荒、城市卫生危机、医疗改善及寿命增长。

**关联：** 贸易与战争可促进疾病传播；公共卫生改善可减轻死亡；长期病害会改变人口结构和国家财政。

**表现方式：** 以地区风险与人口统计为主；默认提供不过度刺激的表现，不以疾病和灾害作为猎奇演出。

## 6.15 自主文明的决策原则（SOC-15）

每个政治或社会主体不是按固定周期随机选择扩张、结盟或战争，而是根据以下维度评估行为：

- **目标：** 安全、资源、稳定、繁荣、声望、信仰、领土、制度延续。
- **能力：** 人口、财政、军事、技术、治理与基础设施。
- **感知：** 可获知的信息、历史经验、邻国关系与不确定性。
- **约束：** 地理、环境、法律、资源与社会接受程度。
- **倾向：** 当前制度、领导集体、文化传统与社会利益结构。
- **后果：** 成功、失败、风险与机会成本。

一个主体的偏好可以随历史变化；短期利益可能与长期发展冲突。用户应该能查看重大决策的主要动因，而非只看到最终动作。

## 6.16 文明生成质量要求

- 智慧物种、文化、语言、宗教和国家是不同层次的概念。
- 城市、人口、贸易和政治不是随机叠加，而是依赖自然和社会约束。
- 支持多民族、多语言、多信仰与边境混合地带。
- 世界既可能出现大型帝国，也可能保留大量小国、游牧地区和自治区域。
- 各类社会制度不存在固定的“天然优劣”，结果由环境与历史共同塑造。
- 在没有用户干预时也可产生形成、增长、衰退、分裂、改革和迁移。

# 7. 时间、历史、世界自主发展与涌现事件

## 7.1 核心目标（HIS-01）

用户可以在不操控任何国家的情况下观看世界独立发展，并能理解每次重大变化来自什么条件、导致什么后果。

**时间分为两个产品层面：**

1. **自然深时（Deep Time）：** 以千年、万年、百万年为观察单位，关注地质、气候、海岸与生态的宏观变化。
2. **文明历史（Historical Time）：** 以年为基础观察单位，必要时按季节或月度展示农业、贸易、战争、疾病和社会变化。

两者共享世界地理背景，但不强求地质演化与文明演化逐秒等速推进。用户应能明确当前查看的是哪一种时间尺度。

## 7.2 世界时间控制（HIS-02）

**基础交互：** 播放、暂停、慢速／正常／快速、指定年份跳转、时间书签、重大事件自动暂停、当前年代提示、观察区间对比。

**进阶交互：**

- 选择“只观察主要事件”“持续观察全部变化”“关注选中实体”三种事件信息密度。
- 在时间轴上显示国家诞生、战争、灾害、技术突破、宗教改革、迁徙浪潮和城市毁灭等标记。
- 可暂时隐藏某一类事件，但不会因此阻止其真实发生。
- 回看世界过往地图与对象资料；查看同一城市在两个年份的差异。
- 从历史时间点复制出新分支，改动条件并继续演化。
- 明确区分过去已发生的事实与对未来的可能性预测。

## 7.3 世界年度演化的产品规则（HIS-03）

一个文明年度应至少体现以下因果顺序（这是规则依赖，不是程序执行方案）：

1. **环境背景更新：** 本年的降水、温度、水量和自然灾害条件。
2. **生产与生活：** 粮食和资源生产、消费、库存、市场供需与基础设施状态。
3. **人口变化：** 出生、死亡、迁徙、城市人口与人口结构。
4. **社会文化变化：** 语言、信仰、教育、文化交流与群体关系。
5. **政治外交变化：** 财政、政策、制度、边界关系、外交与军事。
6. **长期结果：** 技术传播、城市发展、国家兴衰、环境反馈、历史事件生成。

事件可以跨年持续，不能在年末被直接重置。例如饥荒、战争、改革和迁徙都有持续期、阶段和结束条件。

## 7.4 动态系统与时间惯性（HIS-04）

| 系统 | 快速变化 | 中期变化 | 长期变化 |
|---|---|---|---|
| 自然 | 风暴、洪水、火灾 | 连续干旱、冰川变化 | 气候区迁移、海岸变化 |
| 人口 | 疫情、战损、迁徙冲击 | 城市增长、人口结构变化 | 生育模式、区域人口重心变化 |
| 经济 | 价格、贸易封锁、歉收 | 产业转移、基础设施 | 生产方式与经济中心变迁 |
| 文化 | 重大交流和运动 | 语言传播、宗教改革 | 文化融合、语言分化与消亡 |
| 政治 | 政变、战争、条约 | 政策和地方治理 | 王朝更替、帝国兴衰、制度转型 |
| 科技 | 发明或发现 | 采用与普及 | 技术时代跃迁 |

**关键原则：** 变化具有惯性。疆域、语言或产业结构不应因为一个随机数在相邻年份剧烈抖动。

## 7.5 事件体系（HIS-05）

**事件等级：**

- **世界级：** 全球气候突变、多个大陆的疫情、全球贸易重组。
- **跨国级：** 大规模战争、迁徙浪潮、宗教传播、技术扩散。
- **国家级：** 政变、改革、内战、工业化、国家统一与分裂。
- **地区级：** 大旱、丰收、矿脉发现、港口开通、洪水。
- **城市级：** 建城、毁城、改名、人口突破、火灾、公共工程。
- **人物／家族级（高级）：** 领导者继承、思想家出现、王室婚姻、历史人物生平。

**事件必须具有的事实：** 名称、时间、地点、参与实体、触发因素、发展过程、重要结果、持续时间、相关后续事件与历史影响。

事件叙述可以有文学风格，但其事实信息必须与实际模拟状态一致。不能生成从未发生过的战争或将尚未存在的城市写入史书。

## 7.6 事件与自主发展的因果链（HIS-06）

事件并非唯一推动系统的机制；常态变化先在世界中发生，重要阈值和交互条件再形成可叙述的事件。

**典型链条 A｜大河文明兴衰：**

> 稳定季节降雨 → 大河形成可灌溉冲积平原 → 农业剩余 → 城市与专业分工 → 国家治理能力提高 → 干旱持续 → 粮食短缺与税收下降 → 地方不稳 → 迁徙／制度改革／国家分裂。

**典型链条 B｜海峡商业文明：**

> 岛链与狭窄海峡 → 港口天然优势 → 航运技术发展 → 跨海商品流通 → 商业城市联盟 → 文化混合与语言通用化 → 海路受封锁 → 贸易替代路径兴起 → 城市地位变化。

**典型链条 C｜宗教与国家：**

> 商道联通不同地区 → 信仰传播与本土化 → 出现宗教分支 → 国家采用新的官方宗教 → 地方自治与宗教机构发生权力重组 → 改革或冲突 → 新的文化边界。

**典型链条 D｜技术与环境：**

> 新能源与机械技术 → 生产率提高 → 城市化和资源开采 → 排放与生态压力上升 → 局地健康风险或气候影响 → 环境政策、产业转移与技术创新。

## 7.7 历史实体与身份连续性（HIS-07）

国家、城市、民族、语言、宗教和地理实体均应有生命周期与关联记录：

- 建立或首次出现的时间与地点。
- 前身、继承者、分裂者、合并对象。
- 历次名称、首都、边界与属性变化。
- 历次重大关联事件与成就。
- 如果已经消失，保留其终结原因与遗产。

**特殊要求：** “国家灭亡”并不等于该地区居民、语言和城市全部消失；“民族消亡”也不应自动删除其文化影响和历史文献。

## 7.8 历史分支、世界实验与对比（HIS-08）

**功能：** 从任意可用的历史时点建立一条平行世界线；在分支中改变地形、气候、政策、领袖或外交条件，观察不同结果。

**对比维度：** 人口、经济、气候、城市、国界、技术、生态、冲突、重大事件数量及地理变化。

**体验要求：**

- 用户始终知道自己处于哪一个时间分支。
- 原始历史不会因为编辑新分支而消失。
- 支持两条分支在同一时间点地图并排或叠加比较。
- 可查看“在某次干预后的主要差异”，但避免将复杂结果包装成绝对因果结论。
- 可为分支添加描述，例如“北方帝国从未征服海峡”或“雨季延长二十年”。

## 7.9 自主演化模式与世界法则（HIS-09）

用户可以按模块启用或限制：自然灾害、技术扩散、战争、跨海迁徙、国家分裂、宗教传播、生态恢复、疾病等。

**世界法则**表示一个世界长期稳定的规则和允许的事件，不是单纯的作弊开关。若用户关闭战争，模拟器应调整国家竞争的表达方式，而不是让战争状态存在却不展示。

**偏好预设：** 平和文明、激烈竞争、商贸时代、灾变世界、生态优先、完全自由沙盒。

## 7.10 历史模块验收

- 时间推进可使世界产生非平凡变化，而不依赖用户连续点击事件按钮。
- 重大变化有可阅读的发生条件、过程与后果。
- 历史中的已消失对象仍可查找。
- 同一年份的地图、统计和事件事实一致。
- 可以将一个历史时点作为新故事的起点，并与原世界对比。
- 玩家能够区分“已发生的历史”与“尚未确定的未来”。

# 8. 3D 星球、2D 地图与内置图层样式

> 产品目标：既是可探索的真实感星球，也是专业、清晰、有审美表达的世界地图集。地图样式不能改变世界事实；只有显示方式、强调重点和制图语言发生变化。

## 8.1 地图视图（MAP-01）

| 视图 | 定位 | 关键体验 |
|---|---|---|
| **3D Globe** | 行星整体观察 | 自转、昼夜、地形、海洋、云层、星空与全球态势 |
| **2D Atlas** | 地图探索与编辑 | 平移缩放、专题图、边界、标注、线面编辑 |
| **正射球面视图** | 介于地图与星球之间的球面观察 | 在保持球形感的同时突出区域形态 |
| **历史对比** | 不同年代／分支比较 | 分屏、差异高亮、滑动对比 |
| **局部区域图** | 城市和流域的深度浏览 | 更丰富的地形与要素层级 |

2D 提供等距圆柱、墨卡托、Equal Earth 等常用投影，并在投影切换时保持用户关注的地理位置。地图应尊重经线环绕、极区和投影接缝，不允许跨越日期变更线的道路和河流凭空断裂。

## 8.2 三层地图模型（MAP-02）

每张地图由三部分构成：

1. **底图 Base Map：** 一次主要强调一种视觉背景，如自然地形、卫星风格、政治制图。
2. **专题 Thematic Layer：** 展示某一类地理或社会变量，如温度、民族、国家、贸易额。
3. **覆盖层 Overlay：** 河流、城市、道路、国界、标签、经纬网、测量线、事件标记等可叠加要素。

**规则：** 专题叠加应有明确的主次和透明度控制；具有互斥意义的覆盖色块应提示冲突或提供混合方案。图例随当前可见图层同步更新。

## 8.3 内置视觉风格 Presets（MAP-03）

以下是建议自带的视觉样式。颜色是默认色彩方向与设计参考，不要求每个地形类别只能使用一个固定色。

| 风格 | 用途 | 陆地／地形主色 | 海洋主色 | 标签／边界特点 |
|---|---|---|---|---|
| **Standard Atlas 标准地图** | 默认世界概览 | 浅绿 `#91B77C`、高地褐 `#B8A182` | 浅蓝 `#8BC5DE` | 深灰标签、低干扰边界 |
| **Satellite 仿真卫星** | 行星观感与自然景观 | 植被深绿 `#365C38`、裸岩 `#9A856D` | 深海蓝 `#10385A` | 少标签、地形与光照优先 |
| **Physical Relief 自然地理** | 山地、流域、地貌 | 低地绿 `#6DAB6B`、山地棕 `#8D6F56`、雪 `#F5F7F8` | `#5EAFD6` | 晕渲、等高层次明显 |
| **Political Atlas 政区地图** | 国家与行政区 | 柔和离散国家色系 | `#DCEBF0` | 国界清晰、首都醒目 |
| **Minimal Light 极简明亮** | 日常阅读、干净导出 | `#F1F1E9` | `#DCEAF2` | 细线、低饱和、简洁标签 |
| **Minimal Dark 极简暗色** | 夜间探索与数据图 | `#232C34` | `#111D2B` | 灰白字、青色高亮 `#7AC7C4` |
| **Topographic 地形测绘** | 海拔、坡度、地质调查 | 浅褐 `#D8C6A1` | `#A4CADA` | 等高线、阴影、坐标网 |
| **Bathymetric 海洋测深** | 海底结构与洋流 | `#E7E3D7` | 浅海 `#75C8E0` → 深海 `#082C54` | 深度图例、海底命名 |
| **Climate Scientific 气候科学** | 温度、降水、风场 | 中性 `#E5E9E3` | `#D7E4E9` | 统计、分级色带和单位优先 |
| **Biome & Ecology 生态地图** | 生物群系与自然覆盖 | 森林 `#347D53`、草原 `#B6C973`、荒漠 `#D8C18B` | `#80B3C8` | 生境区块、生态图例 |
| **Population & Economy 人口经济** | 密度、财富、交通 | 中性浅底 `#E9E8E0` | `#CFDFE6` | 连续色带、城市规模与商流 |
| **Historical Parchment 羊皮纸** | 古典历史地图 | 羊皮纸 `#E9D5AB` | 米蓝 `#AEC6BC` | 棕黑墨线 `#463C30`、装饰风格 |
| **Fantasy Cartography 奇幻古地图** | 奇幻世界观 | 暖纸 `#E7D5B4`、浮雕山脉 | 灰青 `#9AB8B4` | 手绘地貌符号、特色地名 |
| **Imperial Chronicle 帝国史图** | 王朝、疆域与历史 | 低饱和国家配色 | `#D4DEE1` | 王朝边界、战争与年代注记 |
| **Night Lights 文明夜光** | 城市化与能源使用 | 夜地表 `#101719` | `#06121F` | 人口及活动亮点 `#F9C978` |
| **Monochrome Print 单色印刷** | 出版、研究与线框 | `#F7F6F2` | `#EFEFEA` | 黑白灰、纹理或线型区分类别 |

**重要：** Satellite 为程序化渲染风格，Night Lights 为基于人类／智慧文明活动估计的可视化，不应误称真实卫星观测数据。

## 8.5 覆盖层与地图装饰（MAP-05）

覆盖层至少分组为：

1. **自然边界：** 海岸、河流、湖泊、山脊、流域、板块、冰川、等高线。
2. **人文边界：** 国家、行政区、争议区、文化区、语言区和宗教区。
3. **点要素：** 城市、首都、港口、矿山、火山、圣地、遗迹、战场、事件标记。
4. **线要素：** 道路、航线、运河、铁路、河流、迁徙、贸易、军事行动。
5. **图文要素：** 地名、注记、纹章、旗帜、图例、比例尺、经纬网、方位、测距与剖面。
6. **视觉效果：** 地形阴影、云层、海洋浪纹、夜间灯光、季节积雪、雾霭、光照与事件高亮。

每个覆盖层可单独显示、隐藏、调整透明度；具备明确的层级顺序，允许组合保存为自定义地图方案。

## 8.6 关键地图视觉规范（MAP-06）

### 政治与行政边界

- **国际边界：** 比行政区线更醒目；常态使用深灰或深色细实线。
- **行政边界：** 更细、透明度更低，避免在全局视图形成噪声。
- **争议边界：** 使用虚线或纹理，不能误画成已确定的主权归属。
- **历史边界：** 使用与当前边界区分的半透明轮廓，并注明年份。
- **实际控制范围：** 支持表达控制强弱，而不是只有二元归属。

### 河流与交通

- 河流线宽随流量、等级或制图尺度变化；湖泊与入海口自然衔接。
- 陆路、海路、铁路和运河使用可辨别的不同线型。
- 商贸流向与实体路线区分：路存在不代表始终有货物流动。
- 只在相关尺度显示小型道路或支流，保持地图整洁。

### 城市与地名

- 全球尺度显示首都、都会和战略大城市；区域尺度再逐级显示城镇、村庄、景点。
- 名称不会随缩放发生无意义跳动；优先显示重要对象，避免大面积遮挡。
- 地理名称支持本地名、官方名、历史名及可选译名。
- 山脉、海洋、河流和国家标签可采用不同排版方向与字重。
- 颜色区分类别，但不以颜色作为唯一识别手段，兼顾色觉障碍用户。

### 专题图与统计

- 连续数值使用有单位的连续色带；增长／减少使用以零为中点的发散色带。
- 类别使用可辨认的离散调色板，避免相邻国家出现难以区分的同色。
- 统计图例解释缺测值、未居住、未划归及零值的不同意义。
- 显示覆盖混合程度和不确定性，避免将相对多数民族误当作绝对一致文化。
- 主题切换不改变实际世界数据、时间位置及当前关注地点。

## 8.7 四个缩放层级（MAP-07）

| 层级 | 优先显示 | 默认隐藏或聚合 |
|---|---|---|
| 全球 | 大陆、大洋、主要山脉、国家、首都、重大事件 | 小道路、村庄、细行政边界 |
| 洲际 | 主要河流、贸易干线、区域城市、文化圈 | 支流、低等级聚落与细节标注 |
| 区域 | 行政区、城市、道路、流域、矿产和农业区 | 仅规模极小的细节 |
| 地方 | 聚落细节、河道、水库、道路、地貌点、编辑节点 | 根据用户设置显示全部相关要素 |

不是简单地按固定缩放比例隐藏对象，还应结合实体重要性和当前主题。例如“宗教地图”需要始终突出重要圣地，而“水文地图”需要突出河源和入海口。

## 8.8 图层预设组合（MAP-08）

提供开箱即用的一键组合：

- **地貌探险：** Physical Relief + 河流 + 山脉名 + 主要聚落。
- **帝国时代：** Political Atlas + 国家／行政边界 + 首都 + 道路 + 国家标签。
- **人类地理：** 标准底图 + 人口密度 + 城市规模 + 主要运输网络。
- **文明交汇：** 淡底图 + 文化／语言／宗教专题 + 圣地与历史商道。
- **经济世界：** 浅底图 + 资源／生产 + 港口 + 贸易流 + 市场。
- **生态调查：** 生态底图 + 生物群系 + 土地覆盖 + 河湖 + 风险点。
- **历史战争：** 古典史图 + 指定年份国界 + 战线 + 战役 + 事件。
- **科学气候：** 气候底图 + 月份 + 风场／洋流 + 图例 + 地区统计。
- **纯净出版：** 极简明亮／单色 + 指定边界和标签 + 比例尺。

## 8.9 样式自定义（MAP-09）

用户可调整：主题色板、海陆颜色、地形高度色带、各图层颜色和透明度、线宽、线型、符号、图标大小、字体体系、地名显示密度、光影、纹理、标签语言和图例布局。

可将完整组合保存为“我的样式”，可重命名、复制、恢复默认，并在不同世界之间使用。样式是视觉主题，不应拥有改变国家人口或河流流量的能力。

**验收：** 同一世界、同一时间切换不同样式时，选中对象和地理事实不变；3D 与 2D 都能表现主要图层；地图导出清晰、图例完整、信息不过量。

# 9. 世界编辑器与创世干预

> 编辑器不是在地图上额外涂一层颜色，而是让创作者能够有意识地改变世界事实，并明确知道这些改变会影响什么。

## 9.1 编辑理念（EDT-01）

1. **任何主要地理或人文对象都应可选中、可查看，具备明确的编辑权限与约束。**
2. **修改一个对象不默认破坏其他无关对象。** 用户可以指定保留城市、国界或生态的某些人工设定。
3. **自动生成与人工创作可以共存。** 用户设定的事实应标记为人工设定，并可选择锁定。
4. **编辑具备可预览影响范围、确认、撤销和重做。** 大范围修改应提示潜在后果。
5. **时间中的编辑有明确位置。** 在过去修改与在现在修改是不同的操作；过去的修改可以通过分支历史继续演化。

## 9.2 编辑模式与工具分类（EDT-02）

| 编辑域 | 典型工具 | 可修改内容 |
|---|---|---|
| 地理地形 | 高程画笔、平滑、抬升、削减、山脉线、海岸工具 | 地形、岛屿、大陆形态 |
| 水文 | 河道绘制／改道、湖泊编辑、流域检查、坝体、灌溉 | 河湖、水利设施与淡水条件 |
| 气候生态 | 气温／降水调整、植被画笔、生态恢复、禁伐区 | 气候条件、土地覆盖、保护区 |
| 资源 | 矿床放置、矿藏范围、农田／牧场／渔场 | 资源分布、土地生产能力 |
| 聚落城市 | 放置、移动、升级、改名、功能、人口设置 | 城市、港口、首都、地标 |
| 交通 | 绘制道路、航线、运河、桥梁、铁路 | 交通连接与通行条件 |
| 文化物种 | 绘制分布、迁移起点、语言／信仰编辑 | 身份、传播基础与社会构成 |
| 国家与行政 | 建立、拆分、合并、重划边界、首都与政体 | 领土、行政区、外交关系 |
| 历史与叙事 | 添加事件、建立关系、定义情景和触发条件 | 起始历史、历史干预和自定义事件 |
| 地图装饰 | 标签、纹章、注释、方位、图例、符号 | 仅可视化，不改变世界事实 |

## 9.3 地形编辑（EDT-03）

**基础工具：** 抬升／降低、平整、平滑、噪声地形、山脊／峡谷、区域选取、海平面调整、岛屿创建、海岸修整。

**高级工具：** 高原、火山、冰川、侵蚀强度、地形模板、地貌保护、地形剖面与高度范围限制。

**交互要求：**

- 笔刷半径、强度、边缘过渡、连续／单次作用可调。
- 修改过程提供实时地形预览与高程参考。
- 可锁定一个地貌避免受到后续大范围自动调整影响。
- 海岸变化应提示对河网、生态、人口、城市与领土的影响。
- 对超出物理规则的改造，标记为“人工设定”或“超现实情景”。

## 9.4 文明编辑（EDT-04）

**国家编辑器：** 国名、国旗／纹章、首都、政体、主张与实际领土、行政区、外交关系、文化结构、政策与历史资料。

**聚落编辑器：** 城市位置、名称、规模、功能、基础设施、人口构成、资源联系、建筑风格主题。

**民族／语言／宗教编辑器：** 起源、名称、分布、关系、改革、分支、圣地、文化影响与共同使用范围。

**资源与经济编辑器：** 特定区域的资源、生产部门、市场联系、贸易协定与重要产业。

**规则要求：** 迁移首都不自动消灭原城市；合并国家不自动同化全部人口；修改一种宗教的官方地位不应直接改变所有人的信仰。

## 9.5 依赖影响预览（EDT-05）

这是世界编辑器最重要的区别性功能之一。

**示例：将某条河流改道。**

确认前展示可能受影响的系统：

- 受影响流域、水源及湖泊。
- 沿岸耕地的灌溉适宜性。
- 城市供水和洪水风险。
- 河运和贸易路线。
- 长期的人口及经济发展潜力。

用户可选择：

| 操作方式 | 含义 |
|---|---|
| 只改视觉 | 仅改变绘制的地图符号或注记，不改变世界事实 |
| 修改事实并更新关联 | 接受依赖变化，由世界规则更新受影响状态 |
| 修改事实并保留指定设定 | 锁定所选城市、国界或特殊资源等人工设定 |
| 从该时点创建分支 | 以此修改为起点观察一条新的历史 |

需要明确说明部分后果是确定的直接变化（例如城市失去临河位置），部分只是长期模拟中可能发生的间接结果（例如城市衰退）。

## 9.6 局部重建与锁定（EDT-06）

用户可以重新生成指定类型的内容，而无需放弃整个世界：河网、生态、城市、道路、国家、宗教等。

**锁定粒度：** 单对象、指定区域、某类地理对象、整类系统，以及指定历史实体。锁定规则必须可见，局部生成应在开始前给出保留与可变更内容摘要。

**关键验收：** 在锁定一座城市及其名称的情况下更新周边道路，不应无提示地删除该城市或改掉其身份。

## 9.7 历史编辑与情景创作（EDT-07）

支持以下创作行为：

- 设定一场历史灾难、技术发现、改革、移民浪潮或战争。
- 将一个国家或城市设置为起始情景的重点实体。
- 设置历史前提：某个帝国在起点已经存在、某条旧商道曾经繁荣。
- 修改不同实体之间的关系和已有历史记录。
- 从当前世界建立“如果没有这场战争”的历史分支。
- 编辑事件时区分**已经发生的既定历史**与**未来可能触发的情景规则**。

在创作历史时，系统需检查时间先后和实体存在性。例如不能在城市建立之前把它设为某条贸易协定的签约城市，除非用户调整相关事件时间。

## 9.8 编辑体验与效率（EDT-08）

- 多选、框选、按属性筛选、批量修改。
- 撤销／重做、操作历史、原样恢复、变化比较。
- 画笔快捷预设和镜像／区域复制工具。
- 可保存编辑器工作区：工具、图层组合、关注区域。
- 生成后的人工修改有显著标识，但不影响正常地图美观。
- 支持“只读观察”与“可修改模式”，避免误操作。

## 9.9 编辑器验收

- 能创建或删除岛屿、河流、城市、道路、国家和圣地。
- 对主要修改给出影响对象预览；影响未知时明确说明。
- 可以撤销一个完整编辑操作，不留下半完成状态。
- 可分别保存自然事实、人文事实和纯视觉注释。
- 编辑后的世界仍可查看百科、统计并进入演化模式。
- 地图与世界资料不会出现长期不一致的状态。

# 10. 世界百科、观察、统计与叙事

## 10.1 世界百科（ATL-01）

百科是**世界事实的阅读界面**，不是与模拟脱节的自动写作页面。

**核心目录：**

- **宇宙与天体：** 恒星、行星、卫星、轨道与基本环境。
- **地理：** 大洲、海洋、山脉、河流、湖泊、流域、岛屿、火山、沙漠。
- **自然：** 气候区、生态区、资源、重要灾害、生物物种。
- **社会：** 物种、民族、语言、文化、宗教、职业／社会群体。
- **政治：** 国家、行政区、王朝／政治集团、联盟、条约、战争。
- **城市：** 首都、港口、重要城市、历史遗迹和地标。
- **历史：** 时代、事件、人物、迁徙、改革、发明、消失的文明。

每个百科条目至少包含：名称、分类、当前状态、位置或活动范围、主要属性、时间信息、相关实体、地图定位与历史记录。

## 10.2 地区探索面板（ATL-02）

用户选中任意地点，可看到以下统一信息：

| 面板标签 | 内容 |
|---|---|
| 地理 | 经纬度、地貌、高程、所属大陆与流域 |
| 自然 | 温度、降水、生态区、土壤、水源、资源和自然风险 |
| 人口 | 居民数、人口密度、年龄结构、迁徙和生活水平 |
| 社会 | 物种、主要族群、语言、文化、宗教构成 |
| 经济 | 生产、商品、土地利用、市场可达性 |
| 政治 | 当前国家、行政区、控制与争议情况 |
| 交通 | 最近城市、道路、港口和商路联系 |
| 历史 | 建城、灾难、战役、疆域变化、代表性事件 |

当前地点没有文明时，明确显示“无人居住”而非缺少数据。海洋区域展示海深、洋流、生态和航道，而不是被当作无意义空白。

## 10.3 世界指标仪表盘（ATL-03）

**全球统计：** 世界人口、城市数、国家数、主要物种数量、陆地比例、生态分布、粮食产出、贸易规模、重大灾害、战争数量、生活水平指标。

**区域统计：** 人口趋势、产业结构、降水／温度、粮食安全、迁移、地方稳定性、文化构成。

**专题统计：** 国家面积及人口排行榜、城市等级分布、贸易网络、宗教变化、语言使用人数、战争持续时间与损失、生态退化速度。

**图表交互：** 选择时间范围、筛选对象、固定对照组、定位到地图、按事件标记解释数据拐点。

## 10.4 因果解释面板（ATL-04）

提供标准化的“为什么会这样”体验：

- **为什么这里成为大城市？** 水、耕地、市场、港口、政治中心、历史积累。
- **为什么国家正在衰退？** 粮食不足、财政恶化、治理成本、战争或人口迁出。
- **为什么这里形成荒漠？** 纬度、盛行风、地形雨影、海陆距离和气候变化。
- **为什么宗教扩张？** 商道、传播网络、国家支持、当地人口结构。

解释以**已知贡献因素、相对权重或定性强弱、历史变化和相关证据**构成。对于模型未明确计算的关系，应说明“可能相关”，不能假装给出精确因果。

## 10.5 历史图鉴与世界编年史（ATL-05）

**世界编年史：** 按年代组织全球重大事件，可切换到国家、城市、宗教或人物的专属年表。

**历史档案：** 国家起源与继承、疆域演变、历史首都、历次战争、城市兴衰、宗教传播、技术扩散、消失的文明。

**叙事卡片：** 每张故事卡显示事件标题、时间、地点、关键参与者、起因、过程、后果、地图链接和前后地图变化。

**世界史书：** 自动按年代表整理世界史章节，允许创作者补充命名、摘要与注释，但不改变底层事实。

## 10.6 地图故事与演示（ATL-06）

创作者可将世界制作成一段可阅读的地图叙事：

1. 选择时间地点与图层。
2. 添加旁白或说明文字。
3. 记录关键地图视角与突出对象。
4. 切换下一个年代或事件。
5. 形成可播放、可浏览的历史故事。

**预置故事类型：** 一条河流如何养育文明、海洋贸易中心转移、一种信仰如何扩散、帝国五百年、某片森林如何退化与恢复。

## 10.7 研究与交互工具（ATL-07）

- 全球搜索与模糊搜索：地名、城市、国家、人物、事件、山脉、流域、宗教等。
- 测距、面积、地形剖面、路线比较与流域追踪。
- 收藏与跟踪：关注某个城市、国家、民族、河流或历史人物。
- 对比：任意两个地区、国家、时代或世界分支。
- 过滤与查询：按人口、气候、资源、历史年代、政体等查找对象。
- 注释与书签：为地点和事件添加自定义说明，不改变模拟事实。

## 10.8 百科与叙事验收

- 每一类主要世界实体均可从地图定位到百科，从百科返回地图。
- 世界变化后的旧名称、旧国界和已消失实体仍可查询。
- 统计总量有明确口径；图例、地图与表格数值一致。
- 自动生成的事件叙述不编造不存在的实体或相互矛盾的日期。
- 用户无需阅读算法说明，也能理解至少三个典型自然—文明因果案例。

# 11. 情景模式、挑战与扩展内容

## 11.1 情景实验室（SCN-01）

情景实验室提供可复用的世界问题，让玩家观察各种反事实发展：

| 情景 | 起始条件 | 主要观察问题 |
|---|---|---|
| 干旱三十年 | 两个农业核心区持续降水不足 | 谁会迁移、贸易会怎样、国家能否应对？ |
| 海峡开放 | 新的航路或海峡成为通道 | 哪些港口兴盛、哪些陆路衰落？ |
| 帝国继承危机 | 统治者更迭、地方权力分散 | 会改革、自治、分裂还是内战？ |
| 黑暗冰期 | 气候长期降温，生长季缩短 | 人口和生态边界向哪里移动？ |
| 革命性能源 | 重要新能源和技术被发现 | 哪些产业、城市与贸易网络重组？ |
| 大洪水时代 | 主要流域频繁洪涝 | 灌溉、迁居、财政和水利如何发展？ |
| 疫病沿商路传播 | 高交流城市出现疫病 | 贸易、医疗、人口和政治信任如何变化？ |
| 无国家世界 | 初始只有部落与自由聚落 | 国家会从什么条件下自发形成？ |
| 群岛千年 | 极端岛屿环境、多文化起源 | 海上帝国、孤立文化和宗教如何演化？ |
| 双文明起源 | 两个地区独立出现智慧文明 | 何时相遇、合作、冲突与融合？ |

## 11.2 目标与挑战（SCN-02，可选）

核心产品允许纯沙盒。挑战模式则为部分用户提供目标，例如：

- 在干旱条件下维持指定地区一百年粮食安全。
- 促进跨洲贸易，维持多个文明的和平交流。
- 保护一片高生物多样性生态区。
- 让一个孤立岛屿文明与外部世界建立稳定联系。
- 以最低人口损失处理一次极端环境灾难。

挑战关注多个指标，不把武力扩张作为单一成功标准。

## 11.3 奇幻与科幻扩展（SCN-03，愿景）

**奇幻规则扩展：** 魔法能源、非典型生态、生物种族、龙与神话生物、超自然灾害、神权奇迹和特殊地理。每项规则明确标识超自然前提及对资源、交通、社会的作用。

**科幻扩展：** 轨道殖民、行星工程、极端大气、外来殖民者、星际接触、先进能源与自动化社会。

这些扩展应作为可选世界法则，不侵入默认类地球的科学一致性体验。**跨星系帝国管理不作为当前产品核心范围。**

## 11.4 自定义世界内容（SCN-04）

创作者可以保存自己的物种模板、文化命名习惯、宗教体系、政体设定、世界原型、地图样式和事件情景，供后续世界创建使用。

自定义内容应注明来源、作者、适用世界规则及主要兼容条件。未经用户允许，不自动把创作者的原创内容共享为公共内容。

# 12. 产品设置、内容管理、分享与导出

## 12.1 世界保存与恢复（PRD-01）

用户创建的世界必须保留：世界名称与描述、自然事实、社会事实、当前年代、历史档案、人工修改、锁定、关注对象、地图样式、时间书签和世界分支关系。

提供世界列表、最近打开、复制世界、重命名、归档、删除确认及恢复错误提示。

**明确区分：**

- **重新生成相同起点：** 依据创世条件重新创建初始世界。
- **保存完整世界：** 包含当前演化与编辑后的实际状态。
- **导出地图：** 只导出指定时刻和样式的视觉制图结果。
- **分享情景：** 让其他用户从指定世界前提开始观察或继续创作。

## 12.2 导出与创作成果（PRD-02）

| 成果 | 用户用途 |
|---|---|
| 高质量地图图片 | 文章、故事、桌游、展示 |
| 世界政治图与自然图集 | 设定集、出版和收藏 |
| 专题统计表 | 研究、对比、游戏平衡分析 |
| 地理要素与属性数据 | 在其他地图工具中继续创作 |
| 世界百科文本 | 小说、世界观设定、TRPG 资料 |
| 历史年表 | 战争、王朝、科技、宗教的发展梳理 |
| 地图故事与历史演示 | 视频／演示材料、教学与叙事 |
| 完整世界档案 | 保存全部当前状态及历史内容 |

导出必须包含地图比例、时间、世界名称以及用户选择的必要图例。用户应能选择包含或隐藏注记、界面元素和创作者标识。

## 12.3 分享与社区（PRD-03，后续）

- 分享一颗静态世界、完整世界档案、指定历史分支或情景。
- 发布世界地图与故事，并附世界简介、作者、原始规则和已知限制。
- 他人可复制情景独立创作，不直接修改原作者的世界。
- 具备作品许可说明、内容署名和版本描述。
- 可按地貌风格、历史时期、文明主题和创作目的浏览作品。

## 12.4 个性化与无障碍（PRD-04）

- 中文／英文界面；地名展示支持本地化名称与原名。
- 浅色、暗色和高对比度 UI；字体大小、地图标签密度可调。
- 关键专题图支持色盲友好方案和纹理辅助区分。
- 可关闭镜头旋转、动画闪烁、强烈灾害效果，支持减少动态效果。
- 完整的快捷键查看、操作提示与误操作撤销。
- 重大事件通知可按类别与严重度调整，避免通知淹没观察体验。

## 12.5 内容可信性（PRD-05）

- 明确区分生成事实、模拟事实、用户编辑和视觉注释。
- 可查看世界规则、使用的预设、主要参数和当前历史分支。
- 对需要高度简化的自然或社会机制说明其为“模型近似”。
- 数据与叙事发生冲突时，优先修正叙事而不是悄悄修改世界事实。
- 对所有大范围编辑、删除和历史分支操作提供清晰确认与恢复方式。

# 13. 功能优先级、阶段范围与验收标准

> 完整愿景是长期产品蓝图，不等于第一版需要同时拥有全部功能。阶段以**用户能完成的完整体验**来划分，而不是按代码目录划分。

## 13.1 优先级定义

| 级别 | 定义 |
|---|---|
| **P0 基础必备** | 不具备则无法完成产品最基本的“创建并探索世界”体验 |
| **P1 核心扩展** | 建立真正的时间发展、文明因果与可持续创作体验 |
| **P2 深度模拟** | 提供经济、政治、文化与生态的长期复杂联动 |
| **P3 创作者专业能力** | 全面编辑、历史分支、世界百科及高级地图作品 |
| **P4 愿景能力** | 高级情景、细粒度历史人物、奇幻／科幻等模块 |

P0–P4 是**交付优先级**，不代表单个模块的理论重要性。

## 13.2 第一阶段：Genesis & Atlas（创世与地图集）

**目标：** 用户生成一颗完整的自然与人文星球，切换专题图，探索国家、城市、文化和宗教，并保存成果。

**必要能力：**

- 类地球及典型地理原型，种子与基础创世参数。
- 球面地形、海陆、板块、大洲、主要地貌。
- 季节／月度温度、降水、河流、湖泊基础、气候分类与生物群系。
- 人口、聚落、道路与海路、民族语言、国家、宗教的初始快照。
- 3D 星球、2D 地图、自然和政治专题图。
- 标准／卫星／地形／政治／暗色／羊皮纸等首批内置样式。
- 地区、城市、国家、自然要素的详情信息。
- 世界保存、恢复、地图图片导出。

**首阶段允许暂不具备：** 完整经济市场、长时间文明演化、战争和外交自主决策、复杂编辑器、完整历史分支。

**完成标准：** 用户能独立创建、浏览、命名、保存并重新打开一颗具有自然与文明内容的星球；地图上的主要数据一致、风格可切换、地区可解释。

## 13.3 第二阶段：Living World（活世界）

**目标：** 世界在没有用户操作时也会产生可信的时间变化。

**新增能力：**

- 文明年代、播放暂停、速度和事件时间轴。
- 人口出生／死亡／迁徙、农业产能、粮食供给。
- 城市增长与衰退、聚落出现与消失。
- 基础国家稳定性、扩张、分裂、领土变化。
- 简化外交关系、联盟、冲突及和平。
- 自然灾害影响人口、交通和生产。
- 技术扩散与基础文化宗教变化。
- 关键事件记录、选中实体的历史、基础时间回看。

**完成标准：** 在多个不同初始世界中连续推进约 300–500 个文明年，可观察到不同的发展轨迹；世界总人口与区域统计一致；城市和国家的兴衰可以说明主要原因。

**质量约束：** 不能为了制造变化而频繁随机创建和删除国家；边界变化需要可解释的政治或军事过程。

## 13.4 第三阶段：Society & Economy（深度文明模拟）

**目标：** 让社会变化由生产、市场、技术、制度和资源约束共同驱动。

**新增能力：**

- 自然资源与土地利用、农林矿业和生产部门。
- 区域供需、贸易商品、库存、市场价格及物流瓶颈。
- 税收、基础设施投资、治理预算、区域生活水平。
- 年龄结构、职业与阶层、教育和公共卫生。
- 国家制度、政治集团、自治、改革与社会冲突。
- 更完整的外交、战争、战争损失与战后和平。
- 技术发明与传播、工业化和生态影响。
- 经济地图、财政图、社会结构与贸易流可视化。

**完成标准：** 不同资源地理与政策选择导致显著不同的经济和社会轨迹；贸易中断能够影响依赖地区；国家财政和社会稳定既非完全随机，也非单纯由人口决定。

## 13.5 第四阶段：World Creator（世界创作套件）

**目标：** 将产品升级为能够持续保存人工设定的世界编辑与内容创作环境。

**新增能力：**

- 高程、海岸、河流、湖泊、生态和资源编辑。
- 聚落、道路、国家、行政区、文化、语言、宗教编辑。
- 编辑影响预览、对象锁定、局部更新、批量操作与撤销重做。
- 自定义地图样式、注记、纹章与出版地图。
- 世界百科编辑、历史事件注释和地图故事制作。
- 完整世界档案、创作者内容与基础分享。

**完成标准：** 用户可以创作一个包含人工地貌、国家、城市和文化的世界，并在继续运行文明时间时保留指定人工设定。编辑后不出现统计或历史矛盾。

## 13.6 第五阶段：Chronicle & Experiments（历史实验室）

**目标：** 让用户主动研究“如果历史改变会怎样”。

**新增能力：**

- 历史年份跳转、完整实体沿革、消失对象检索。
- 时间分支、多世界对比、历史地图和差异分析。
- 自定义历史情景、事件条件和情景实验室。
- 重点人物、王朝／家族与政治团体的跨时代记录。
- 长期自然变化、海平面变化、生态恢复与长期气候事件。
- 自动组织世界编年史、可播放地图故事与历史图集。

**完成标准：** 用户能够在某一年创建两个分支，让一个关键条件不同，继续运行、比较结果并输出带时间标记的历史地图和事件摘要。

## 13.7 第六阶段：扩展宇宙（长期愿景）

**方向：** 非类地球天体、复杂多物种文明、完整生态食物网络、精细人物家族史、深时地质演变、奇幻物理规则、科幻社会与星际接触、丰富创作社区。

这些能力应建立在核心世界规律、创作工具与历史体验成熟之后。

## 13.9 通用验收原则

任何新功能必须通过以下跨系统检查：

1. **正确性：** 世界事实与相关统计不矛盾。
2. **可解释性：** 影响重要结果的主要因素可查看。
3. **可发现性：** 用户能从地图或目录找到该功能。
4. **时间一致性：** 事件日期、实体生命周期和地图年份一致。
5. **编辑一致性：** 可编辑内容修改后，相关视图和资料同步变化。
6. **视觉一致性：** 不同地图样式不改变数值事实。
7. **内容完整性：** 空值、异常世界、无人区、未划归区域有明确表现。
8. **回归稳定性：** 相同创世条件在同一内容版本内可重复；历史过程不随切换主题而变化。
9. **性能体验：** 操作有可预期反馈，世界生成、演化和查询不会无限无响应；性能目标以目标设备和基准情景定义。
10. **用户自由：** 支持纯观察，不将任务、排行榜或故事提示强加给创作者。

# 14. 跨系统案例与质量判据

> 为了避免各模块单独验收良好、组合后却失去世界逻辑，以下场景作为产品级验收案例和内容设计样本。

## 案例 1｜雨影与沙漠王国

**设定：** 一条南北走向的高山阻挡盛行湿风。

**预期世界：** 迎风坡降水丰富，背风坡干旱；山脚河谷与绿洲形成聚落；人口依水源和商道分布；国家治理与贸易受山口控制。

**验收：** 气候、河流、人口、交通和政治地图相互支持；解释面板可以展示山脉对降水、人口和通道的作用。

## 案例 2｜群岛商贸文明

**设定：** 多岛屿、重要海峡、适宜航海与渔业的环境。

**预期世界：** 沿岸人口集中、出现港口中心；海运影响市场通达；语言宗教通过航线扩散；政治形式可出现港口联盟和海上强国。

**验收：** 离岛联系需要实际航路或对应跨海能力，不因地图上距离近就自动传播。

## 案例 3｜河流改道导致的城市命运变化

**设定：** 创作者把一条流经农业盆地的主河道改至另一低地。

**预期世界：** 流域水量与灌溉适宜性变化；部分城市港口价值下降；贸易路线可改道；长期可能发生迁移和新城兴起。

**验收：** 编辑前列出影响范围；即时地理事实和长期可能后果分开显示；支持撤销或创建历史分支。

## 案例 4｜长期干旱与人口迁徙

**设定：** 一片人口稠密的半干旱地区连续数十年降雨偏少。

**预期世界：** 粮食生产和储备下降；公共投资、贸易进口及迁移可缓解风险；治理失败时出现社会动荡、城市衰退甚至国家变化。

**验收：** 多个社会主体可以采取不同响应；灾害不必在所有世界中以同一方式结束。

## 案例 5｜资源与工业城市

**设定：** 内陆煤铁产区附近出现新运输路线与冶金技术。

**预期世界：** 矿业与制造业增长、城市吸引劳动人口、基础设施扩张、区域财富上升，也可能出现环境污染与资源衰竭。

**验收：** 产业增长具有资源、能源、劳动力与交通条件；长期繁荣不是无来源的经济数值上升。

## 案例 6｜帝国分裂与历史继承

**设定：** 一个人口庞大、边疆治理成本高的帝国遭遇继承危机。

**预期世界：** 地方势力自主性上升，可能改革或分裂；城市、文化和宗教并不因帝国终结而消失；新国家保留对前帝国的继承关系。

**验收：** 旧帝国在百科和历史地图中仍能检索；新国家的起源、首都与疆域变化可追踪。

## 案例 7｜宗教传播与文化混居

**设定：** 跨越三种语言区的商路沿线出现新信仰。

**预期世界：** 信仰沿城镇网络传播、发生地方化与分支；语言分布不必同时改变，政治边界不必恰好吻合宗教边界。

**验收：** 民族、语言、宗教及国家四张专题图反映不同但关联的分布。

## 案例 8｜气候变化与海岸迁移

**设定：** 长期升温导致冰盖减少、海平面上升。

**预期世界：** 低地与港口受威胁，部分河口城市需要迁移或防护；内陆新港和新通道可能出现；生态区发生迁移。

**验收：** 海岸改变是地理事实变化，不只是视觉滤镜；有记录的旧城市位置和历史海岸仍可回看。

## 案例 9｜文明共同发展而非必然战争

**设定：** 两个国家共享流域，经济互补且文化不同。

**预期世界：** 有可能建立水权与贸易协议，也可能在干旱时竞争；结果取决于利益、制度、关系和环境条件，而不是固定文化冲突。

**验收：** 外交与合作是具有实际收益和结果的机制，不只是战争之间的空档。

## 案例 10｜历史分支实验

**设定：** 在一条重要贸易路线被战争中断前创建两个分支，其中一条保持和平，另一条发生封锁。

**预期世界：** 贸易路线、价格、城市发展、政治关系与文化传播出现不同演化轨迹。

**验收：** 以同一历史时间、相同初始世界条件比较；两条分支都保留可检索的事件链与结果。

## 案例 11｜高纬智慧物种与多生态位

**设定：** 一种智慧物种对寒冷环境适应更好，另一种偏好温暖湿润地区。

**预期世界：** 早期人口位置不同，后续因技术、贸易、移民与制度形成混居区域；不存在物种注定属于某一种政体的硬规则。

**验收：** 生理适应和文化制度被分别表达；迁徙与技术可以改变地理限制。

## 案例 12｜纯创作世界的稳定性

**设定：** 用户手动绘制独特大陆、河流、五个国家与多个命名城市，然后更新气候和资源条件。

**预期世界：** 用户锁定的地形与城市身份被保留，自动衍生的生态和人口适宜性得到调整；所有更改有可追踪的影响提示。

**验收：** 一次自然参数更新不会悄悄抹去整套人工世界设定。

# 15. 产品边界、待决策问题与参考产品

## 15.1 建议现在固定的产品决策

1. **产品中心是一颗星球上的完整世界，而非星际帝国战争。** 星际扩展可保留为长期愿景。
2. **默认强调科学启发的类地球模拟。** 奇幻和科幻通过明确可选的世界规则扩展。
3. **第一阶段以完整生成、探索和地图表达为主。** 历史演化是核心长期目标，但无需为了历史系统推迟一切地图功能。
4. **国家不等于民族，语言不等于宗教。** 混合分布是默认的世界复杂性。
5. **自然与文明具有可解释因果联系。** 不依赖“刷事件”代替生产、交通和政治机制。
6. **观察者是完整的用户身份。** 不强制国家控制、玩家胜利或任务奖励。
7. **人工修改必须被尊重。** 地图编辑和重新生成时不得无提示覆盖已锁定内容。
8. **地图样式只改变表达。** 数据、历史和社会状态不随主题切换而改变。
9. **用户可以追问任何重要变化。** 世界事实、事件、历史和地图保持一致。
10. **历史世界可被保存、回看、分支与创作。** 时间演化不是只能向前的一次性动画。

## 15.2 需要在后续需求细化时讨论的问题

| 决策题 | 备选方向 | 推荐默认 |
|---|---|---|
| 玩家视角 | 上帝观察者／国家统治者／角色扮演 | 观察者与创作者优先 |
| 历史初始时间 | 从智慧生命起源／已有国家 | 两者均支持，先完善已有国家起点 |
| 文明粒度 | 仅区域／区域+城市／每个人 | 区域+城市，人物作为重点对象 |
| 经济深度 | 抽象生产指数／重要商品／完整市场 | 重要商品和地区供需起步 |
| 战争深度 | 边界事件／战略态势／即时战斗 | 战略态势与政治结果 |
| 地质演化 | 静态初始地形／深时回放 | 静态高质量起点先行，深时作为专门模式 |
| 科学与奇幻 | 单一混合规则／清晰模式开关 | 默认科学启发，奇幻可选 |
| 自动叙事 | 数据摘要／生成文字／创作者脚本 | 事实摘要为基础，文学表达可选 |
| 创作者权限 | 完全自由／物理约束／两者兼有 | 默认约束，有意识开启自由创世 |
| 多人体验 | 单人世界／分享作品／实时共创 | 单人创作与作品分享优先 |

## 15.3 产品成熟度判据

| 成熟度 | 用户能做什么 | 世界具有怎样的深度 |
|---|---|---|
| **Level 1：Beautiful World** | 生成、浏览、导出地图 | 可信自然地理 |
| **Level 2：Inhabited World** | 观察城市、国家与文化 | 相互关联的人文快照 |
| **Level 3：Living World** | 推进年代，见证兴衰 | 变化具有因果链 |
| **Level 4：Editable World** | 创作地形、国家与历史 | 人工创作与自主规则共存 |
| **Level 5：Remembering World** | 回看、分支、对比与讲史 | 世界拥有连续身份和可检索历史 |
| **Level 6：World Laboratory** | 比较假设、研究长期反馈 | 多系统深度联动与可解释实验 |

真正的顶级体验并不只是图层更多、参数更多，而是**世界越运行越有历史，用户越观察越能发现原因，用户越编辑越能够掌控自己的创作**。

| Environment | 气候、地貌、水、生态及自然资源的共同条件 |
| Source of Truth | 一个世界事实由其对应领域状态决定，视觉表示不得自行改写该事实 |
| World Law | 规定世界允许和如何发生某类现象的长期规则 |
| Event | 带有时间、地点、参与者、原因和结果的历史变化 |
| Timeline Branch | 从同一历史时点出发的另一条可能发展路径 |
| Base Map | 地图视觉底色及主要背景内容 |
| Thematic Layer | 对某一类自然或社会现象的地理表达 |
| Overlay | 可叠加显示的道路、河流、边界、标签和符号 |
| Editor Override | 创作者直接设定、可选择锁定的世界事实 |
| Scenario | 包含前提、关注目标和可选世界法则的模拟情景 |

# 附录 B：给后续功能设计与需求分解的准则

对每个新功能，后续详细需求至少应回答：

1. **用户价值：** 用户为什么需要它？会因此看见什么、理解什么或创造什么？
2. **适用对象：** 影响整个星球、区域、城市、国家、群体还是事件？
3. **前提和输入：** 需要哪些已存在的世界事实？哪些是可配置条件？
4. **规则和约束：** 怎样变化？有哪些守恒、边界与异常情况？
5. **可见结果：** 地图、百科、统计和事件中如何呈现？
6. **时间表现：** 只决定初始状态，还是每年变化？是否有长期滞后？
7. **编辑行为：** 能否手动修改？是否允许锁定？哪些变化需预览？
8. **历史记录：** 会产生哪些可追溯的事件和实体沿革？
9. **联动对象：** 会如何影响自然、人口、资源、经济、政治与文化？
10. **验收标准：** 至少一个正常场景、一个边界场景、一个跨系统场景。

> **产品总纲：Generate a world. Watch it live. Shape its destiny. Remember its history.**
