# 球面 Delaunay / Voronoi：规则与扰动网格

## API 与兼容性

```ts
const mesh = createSphericalMesh({
  subdivisionLevel: 6,
  physicalRadiusKm: 6371,
  irregularity: 0.75,
  seed: 42,
})
const result = validateSphericalMesh(mesh)
```

`irregularity` 默认为 0，支持 [0,1] 内有限值；seed 默认为 0，接受非空字符串或安全整数，进入 Alea 前转换为字符串。参数越界直接拒绝，不静默截断。generateIcosphere(level, options) 也接受这两个参数。

irregularity=0 完全复用已有中点细分拓扑，不执行扰动和 Delaunator；中心、三角面、规则 meshId 保持不变，忽略 seed 对结果的影响并将输出 seed 规范为 '0'。新增的 irregularity/seed 是 SphericalMesh 与 IcosphereGeometry 的生成元数据，MeshTopology 和 WorldSnapshot schema 未改变。

irregularity>0 使用 `icosphere-jitter-v1` 身份，meshId 包含 level、物理半径、强度及编码后的 seed。不同强度或 seed 不能共享生成缓存。L0 的 12 个原始站点均固定，因此非零强度也不会改变其几何。

## 继承的实现与投影数学

已实际读取并参考：

- docs/old-src/core/mesh/icosphere-builder.ts：Alea、切平面扰动、立体投影、平面 Delaunator 与凸包极点补面。
- docs/old-src/core/mesh/voronoi.ts：球面外心、区域相邻面归集、角度排序及球面三角形扇区面积。

依赖使用 alea 1.0.1、delaunator 5.1.0（自带类型）；不实现新的 Delaunay 求解器。原始 12 个站点固定，其他站点使用旧版相同的独立随机位移：切向幅度上限因子为 `sqrt(4π/N) * 0.75 * irregularity`，两个方向分别由两次随机数之差驱动，然后重新归一化。M0.4 将取数改为注入共享 `RandomSource`；默认与 Pipeline MeshStage 注入均使用新鲜的 `AleaRandom(seed)`，取数次序和几何结果未变。这个经验扰动控制形态，不是地形或物理模拟。

令现有站点 p 为投影极点，取正交基 u、v、p。对其余单位站点 q：

`X = dot(q,u) / (1-dot(q,p))`

`Y = dot(q,v) / (1-dot(q,p))`

实现中分母采用等价的 `|q-p|²/2`，避免接近极点时 `1-dot` 的相消。基底以与 p 最不平行的坐标轴构造，因此没有旧版接近 ±Z 时的 Rodrigues 特殊分支。极点本身从有限投影中移除，不人为将其塞入一个巨大平面坐标。

立体投影将球面圆映射为平面圆或直线。平面空圆三角形反投影为不包含极点的球面空球冠面；投影凸包边对应极点的相邻站点，逐边补上极点三角形闭合球面。最后用三重积校正所有面的外向顺序。整个过程不使用经纬度平面三角化，也不把经度接缝当成边界。

`triangulateSphericalDelaunay(centers, projectionPole=0)` 提供该过程的低层入口，适用于互异、单位长度且覆盖球面的站点集，数量上限 163842。普通生成总是使用 pole=0。投影不可表示、重复站点或数值分辨率不足导致站点被 Delaunator 遗漏时抛错，绝不提交缺面结果；不是任意半球点集的通用凸包 API。

## 对偶与校验

对重建后的每个三角面求外向单位外心；相邻面外心构成 Voronoi 单元的有序边界。面积继续使用球面三角形的立体角公式，乘物理半径平方。按实际最大度数分配局部排序缓冲，不截断到固定的 6、12 或 32 个邻居。

规则网格要求 12 个五邻域，其余六邻域。扰动后度数可以改变，仅要求有效闭合球面单元至少三邻域；两类网格均检查：

- 数量、dtype、有效 CSR 和 Euler 特征；每边恰有两个不同面；双向无重复邻接。
- 单位球中心、非退化外向面、外心等距及相邻面局部 Delaunay 空球冠条件。
- 每个边界角点属于该区域，无重复角点，连续角点共享 incident edge，边界外向。
- 单元正面积、逐单元面积与实际边界一致、总面积接近 4πR²。

邻接校验用每边双向标记代替反复搜索邻居；边界连续性通过面边关联检查，使可变度数校验保持 O(N+E+F)。大数组以 TypedArray 表达，查询与重建不依赖 Three.js、DOM 或 UI。

测试包含多个等级、强度与 Seed 的完整校验，低等级全局空球冠比较；极点位于 ±Z、接近 ±Z、不同极点 ID，以及另一个站点距离极点约 1e-6 弧度的闭合与面积检查。也保留大扰动后旧连接出现翻转面的失败回归。Float64 与新投影基底提高稳定性，但不承诺逐字节还原旧版 Float32 输出或跨引擎末位浮点一致。
