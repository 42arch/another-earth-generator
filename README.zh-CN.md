# Another Earth Generator （异星生成器）

[English](README.md) | [简体中文](README.zh-CN.md)

在浏览器里生成一颗架空的类地星球，并在3D和2D地图中探索它的自然、气候和文明演化。

## 目前能力

### 自然世界

从板块和地形开始，生成大陆、海洋、山脉、岛屿、气候、风与洋流、河流、湖泊和生态。

可以更换随机种子，调整陆地多少、地形起伏、冷暖和干湿。同一组设置会生成同一颗星球。拖动月份，查看气温、降水、风向、洋流和积雪如何随季节变化。

### 文明

在自然条件之上安排人口和聚落，连成陆路、河运和近海航线，并形成族群、文化、宗教、城镇化和国家。

人口多少、城镇疏密、国家是连成大国还是分成许多小邦，都可以调节。

### 地图

用三维星球或平面地图查看世界。平面地图可选等面积、等距圆柱和墨卡托投影。

目前地图支持多种风格：仿真卫星、标准地图、自然地理、政区、明亮或暗色的专题底图，以及古典羊皮纸。

可以单独查看高程、板块、海陆、气温、降水、气候带、风和洋流、生物群系、地表覆盖、农业潜力、矿产、人口密度、国家、文化和宗教等图层。河网、湖泊、海岸线、地名、国界、交通线和城镇等要素可以叠加上去。

点选一块区域、一座城镇或一个国家，查看那里的自然条件和文明信息。也可以看整颗星球的概览，复制分享链接，或把当前地图导出成图片。

界面支持简体中文和英文。

## 代码与开发

仓库是 Bun workspace，使用 TypeScript、Svelte 5 和 Vite。

### 目录

| 路径 | 职责 |
| --- | --- |
| `packages/world-data` | 内容定义、社会候选和名称词库 |
| `packages/world-core` | 星球生成、领域规则和已发布的世界 |
| `packages/cartography` | 地图数据、样式和二维／三维绘制，只读取世界 |
| `apps/web` | 界面、Worker 和浏览器侧编排 |

`apps/web/src` 里，`ui` 是界面，`world-view` 是地图工作台，`workers` 负责生成。

### 本地运行

```sh
bun install
bun dev
```

打开终端给出的地址。细分等级越高，内存占用越大。
